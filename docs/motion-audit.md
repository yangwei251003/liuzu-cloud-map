# 全站动效审计

审计日期：2026-08-17  
基线：当前工作树（含既有字体、首页文化动效、地图数字展馆与移动壳成果）

## 审计结论

网站已有 Framer Motion、CSS View Timeline、Web Animations、高德 / MapLibre / Loca 动效基础。主要问题不是“没有动效”，而是时长、缓动和降级判断分散，部分页面只有局部反馈，首页标题与地图的表现力明显强于内部页面。此次保留全部业务结构和数据契约，用一个动效系统收拢这些能力。

| 范围 | 既有状态 | 本轮结论 |
| --- | --- | --- |
| 全局外壳 | 页面首元素淡入，导航 hover，移动底栏 | 增加按路由分级的非阻塞页面转场、活动导航光带、统一按压与材质反馈 |
| 首页 | Hero 分段揭示、文化纹样、路线描边、媒体轮播、轻 2.5D | 保留并提高层次；移除原始 scroll 监听，避免与现有元素重复 transform |
| 云游 | 章节进度、场景切换、朗读与答题状态 | 归入 cinematic；强化章节卡错峰、图像景深、进度与完成反馈 |
| 到达 / 行程 / 导游 | 表单、路径、内容状态较完整 | 归入 expressive；使用轻揭示、状态变形和快速反馈，不改变字段或流程 |
| 地图 | 高德相机、Marker WAAPI、路线流动、Loca 展馆层 | 归入 utility；保留官方相机与图层能力，不叠加通用页面 reveal，不让演示层暗示事实 |
| 社区 / 主页 / 账号 | 点赞、评论、发布、加载和空状态已有基础 | 归入 expressive；统一卡片错峰、图片景深、确认反馈与对话框转场 |
| 禅小荔 | 十种视觉状态、拖拽、语音、问答、失败态 | 保留状态机和原图；增加状态光圈、呼吸、思考扫光和成功弹性反馈 |
| 管理 / 隐私 / 分享 / 导航实验室 | 操作密集，安全和速度优先 | 归入 utility；只使用快速页面、面板、表单与状态反馈 |
| Loading / 空状态 | 多数核心流程已有 skeleton / role=status | 统一 shimmer 节奏；不人为延长等待；减少动态时停止循环 |
| 移动端 | 地图高负载层已有关闭策略 | 关闭持续环境运动、磁吸、复杂视差和延迟错峰；保留触摸按压和可见状态 |

## 实现规则

- 动画主属性为 `transform`、`opacity`，只在少数叙事揭示使用 `clip-path` 和 SVG 路径长度。
- 同一元素只由一种机制控制位移，避免 CSS、Framer Motion 与地图 SDK 争用 transform。
- 视口进入只播放一次；持续环境动画限制在固定背景与禅小荔状态光圈等少数组。
- 系统 `prefers-reduced-motion` 或站内“简洁显示”任一开启，均关闭循环、视差、磁吸、路径流动与复杂转场。
- 触摸设备不启用 hover 景深；所有点击目标继续满足现有最小触达面积。

## 保留的事实与安全边界

动效不改变地理、路线、开放、文化和游客行为数据。地图飞线、热力、粒子与装饰路径继续使用已有“演示 / 候选”标签；地图聚焦使用 SDK 官方相机能力，导航与路线失败继续失败关闭。
