# 云游地图全站中文字体审计

更新时间：2026-08-18

本审计以游客端真实页面、公共地图、文化内容、AI 导游、IP/云游章节、移动端和共享页面为范围。原则是“艺术字体承载情绪与文化，现代字体承载阅读与操作”，不改变业务接口、路线数据和地图事实。

| 页面 | 区域 | 当前字体 | 当前问题 | 建议字体 | 修改原因 |
| --- | --- | --- | --- | --- | --- |
| 全站 | Header / Navigation | `var(--font-ui)` | 导航必须清晰，品牌气质主要依赖 Logo | UI；副标题使用 `var(--font-display)` | 保留点击识别，品牌标题增加书卷感 |
| 首页 | Hero 主标题 | 前一版混用秀楷与行楷 | 两行字形、粗细和视觉重心不一致 | 方正清刻本悦宋 WOFF2 本地优先 | 两行使用同一主字体，只保留颜色和换行建立层次，首屏更完整统一 |
| 首页 | 推荐路线标题 | Noto Serif | 文化感已有，但路线节点识别还可更温润 | 方正清刻本悦宋 WOFF2 | 路线标题负责结构，景点名负责文化记忆 |
| 首页 | 景点卡片 | 汉仪北魏写经 / 云字体 fallback | 小字号笔性偏跳，和路线标题不统一 | 方正清刻本悦宋 WOFF2 | 统一推荐路线信息的文化宋体，减少一大一小一粗一细的割裂感 |
| 首页 | 宣传轮播标题 | Noto Serif | 图片氛围与文字气质略有断层 | LXGW WenKai | 让实景宣传与文化叙事更统一 |
| 首页 | CTA / 按钮 /说明 | UI | 已适合游客操作 | UI | 不使用艺术字体，避免误读 |
| 地图 | 地图底图、Marker、路线节点 | UI | 必须快速扫描，不能书法化 | UI；选中景点摘要可用 Noto Serif | 保护地图操作与路线辨识 |
| 路线 / 导览 | 路线名与章节开场 | UI 为主 | 结构化路线信息缺少文化入口 | Noto Serif / LXGW WenKai；节点保持 UI | 文化标题与安全指令分层 |
| 文化云游 | 页面 Hero / 景点名 | UI 或统一粗体 | 内容型页面容易像普通工具页 | 方正清刻本悦宋 + 汉仪北魏写经 + LXGW WenKai | 形成书卷、历史和章节感 |
| 文化云游 | 讲解正文 / 来源 | UI | 正文需长时间阅读 | UI；短引言可用 LXGW WenKai | 只在短内容上增加笔性，不牺牲可读性 |
| AI 导游 | 面板标题 | UI 粗体 | 科技感强，文化导游身份不足 | Noto Serif | 保持输入控件 UI，标题引入文化层 |
| AI 导游 | AI 输出标题、文化提示 | UI | 输出与产品文化场景脱节 | LXGW WenKai | 形成“现代能力 + 传统内容”的混排 |
| IP / 禅小荔 | 对话文本 | UI | 角色更像普通客服 | UI + 短故事句 LXGW WenKai | 对话仍可读，故事性语句更像文化导游 |
| 景点详情 | 景点 Hero 名称 | 当前页面级标题 | 需要更强的地点记忆点 | Noto Serif；商业宋刻字体待授权 | 先用可发布字体建立稳定结构 |
| 到达 / 规划 | 页面主标题 | UI / Noto Serif | 工具信息页文化识别偏弱，主标题缺少记忆点 | 方正清刻本悦宋 WOFF2；步骤与提示保持 UI | 用稳定的文化宋体承载“大字”，不把表单与安全提示装饰化 |
| 社区 | 品牌大字 / 地点社区大字 | UI 粗体 | 游客故事与功能标签层级混合，主视觉偏工具化 | 方正清刻本悦宋 WOFF2；标签保持 UI | 大字有旅行氛围但不过分花哨，互动控件仍然清晰 |
| 我的 | 账号主标题 | UI / Noto Serif | 与行程页、首页的文化标题缺少统一性 | 方正清刻本悦宋 WOFF2；账号状态与表单保持 UI | 统一大标题角色，正文和登录操作保持可读 |
| Footer | 品牌中文名 | Logo 资产 / UI | 版权与链接不能艺术化 | Logo / Noto Serif 品牌标题；其余 UI | 品牌与法务信息分层 |
| Loading / Dialog / Drawer / Search | 所有控件 | UI | 不应引入装饰性阅读成本 | UI | 状态反馈、输入、错误信息优先可读 |
| 移动端 | Hero、章节标题 | 继承桌面层级 | 过大字距可能换行或 CLS | 艺术字体保留但收窄字距与字号 | 保留文化感，避免屏幕被标题占满 |

## 当前确认的角色

- `--font-ui`：Noto Sans SC Variable，功能、导航、地图、数据、表单和安全提示。
- `--font-display`：Noto Serif SC Variable，章节标题、页面标题、景点文化名。
- `--font-wenkai`：LXGW WenKai，故事、文化说明、游记片段、社区卡片标题。
- `--font-brush`：Ma Shan Zheng，保留为开源回退和少量文化视觉符号。
- `--font-shangwei`：汉仪尚巍手书，作为秀楷缺字或特殊品牌短句的个性化 fallback。
- `--font-chanqu`：汉仪曾翔禅趣体，禅意标记和一至六字短符号。
- `--font-beiwei`：汉仪北魏写经，历史/文化短标题与景点名的个性化 fallback。
- `--font-qingke`：方正清刻本悦宋简体，页面/章节标题、景点名和文化卡片。
- `--font-xiukai`：方正宋刻本秀楷简体，保留用于开发字体预览和未来短情绪文案，不再拆分首页两行主标题。
- `--font-xingkai`：方正行楷简体，保留用于开发字体预览和需要手写感的短叙事，不作为四个核心页面的大标题主字体。
- `--font-founder-xingkai` / `--font-founder-qingke`：方正官方云字库授权后替换角色，未配置 Key 时回退到本地 WOFF2。
- `--font-note`：系统楷体回退，仅用于轻量文化注释。

## 未采用的候选

方正与汉仪字体均由用户提供本地文件并已转换为 WOFF2 子集；商业 Web/嵌入授权仍以用户凭证为准。对应状态见 `docs/font-license-status.md`。
