## 4. 安全降级边界

当前演示版的关键安全策略经测试确认：

1. 候选坐标、OSM 路线和编辑顺序不被称为正式入口、真实内部路线或安全导航。
2. 正式路线网络清单保持空；没有发布网络、有效路线和新鲜状态时禁止继续自动导览。
3. 位置只给直线距离和粗略方位提示；低精度或不稳定样本不会变成“已到达”。
4. 中途封闭、偏离、未知状态时停止并要求重新核验/询问现场人员，不由 AI 生成替代路。
5. 开放、班次、停车、客流、票价、天气、无障碍和应急渠道没有权威实时源时明确“不知道”。
6. 110/120 只作为全国紧急号码说明，不冒充景区官方求助渠道。
7. 文化回答带来源、类型和核验状态；未完成专业审核的内容不被称为正式发布讲解。
8. 远程游记/问答必须逐次同意；账号口令不进浏览器存储，服务端只存 scrypt 派生摘要和会话 token hash。
9. `/api/`、`/account`、`/admin` 路径均为网络优先之外的强制 `network-only`，不会进入 Service Worker CacheStorage。
10. 本机演示分享把最小载荷放在 URL fragment，明确无法跨设备远程撤销；真实服务端分享必须登录并依赖数据库。
