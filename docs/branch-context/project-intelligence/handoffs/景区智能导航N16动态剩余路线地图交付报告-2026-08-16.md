# 景区智能导航 N16 动态剩余路线地图交付报告

日期：2026-08-16  
结论：软件闭环完成；生产仍为 `NO_GO`

## 1. 修复的问题

正式导航此前虽然实时更新剩余距离和 ETA，地图却始终把整条路线显示为蓝色。游客无法从地图区分已经走过与仍需行走的部分，索道/观光车虚线也会在完成后继续显示。暂停恢复还会清空 tracker，导致文字进度保留但路线匹配重新从零开始，尤其在重叠路线上可能回退。

## 2. 当前实现

- 运行时 tracker 保存仅驻留内存的 `segmentIndex + segmentFraction`，与最后可靠投影、逐边剩余量和连续匹配使用同一证据。
- 纯函数在精确插值点拆分总几何：灰线为最后确认已走，蓝线为剩余路线；起点不生成零长度已走线，精确终点不再生成剩余线。
- 无匹配、越界或损坏匹配返回整条蓝色待走路线和空灰线，不根据总体 `progressRatio` 猜测切点。
- 索道/观光车只保留当前匹配点之后的服务段；若 traversal 总段数与路线几何不一致，隐藏进度敏感交通 overlay，避免将已完成服务误报为待乘。
- MapLibre 使用独立 completed/remaining source 与图层，通过 `setData` 更新，不为每个定位样本重建地图。文字图例和读屏说明同时解释灰/蓝状态。
- 暂停恢复保留最后确认匹配、当前进度与最远进度，但清空前一定位、偏航、到达、远端分支和反向行走连续证据；退出、换路线和重算清空匹配。
- 路线匹配、拆分 GeoJSON 和 GPS 均不上传、不缓存、不进入导航历史或日志。
