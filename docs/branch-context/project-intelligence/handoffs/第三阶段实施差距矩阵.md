## 1. 结论先行

当前准确里程碑是 [`00-项目状态.md`](../00-项目状态.md) 中的 `PUBLIC_DEMO_WITH_BACKEND_FOUNDATION`。仓库已经形成可重复验证的**诚实公开演示 + 受控后端基础切片**：本地 OSM 地图与四维偏好候选路线、游记证据化提取与人工消歧、`RoutePlan` 快照、显式演示导览与前台连续定位提示、本机旅程/知识卡、7 天只读链接、治理/纠错/隐私清除；另有完全不使用定位、明确不等同现场路线的线上云游。

冻结审计确认：

- 最终机器可读 `verify:release` 退出 0：ESLint、TypeScript、**113/113** Node 单元/契约测试、Next.js 生产构建、Playwright **18/18** 均通过；AI GoldenSet v1 **6/6**、Service Worker v3 缓存政策 **5/5** 包含在 Node 结果中。
- 机械计数为 **23** 个 Node 测试文件 / **110** 处静态 `test()` 声明（Node runner 汇总 113 个测试记录）、**6** 个 Playwright spec / **18** 个场景、**11** 个 `page.tsx`、**6** 个 API `route.ts`、**1** 个数据库迁移和 **1** 个 GitHub Actions workflow。Next 构建路由表共 19 项，包含 17 个页面/API 源入口及框架生成入口。
- 最新 Vercel production 部署已绑定[固定预览域名](https://example.invalid)：公网首页和 `/api/health` 返回 200，使用 release summary 对应浏览器的公网 Playwright 复跑 **18/18**。未绑定数据库时，服务端分享创建/读取返回 503 `CAPABILITY_DISABLED` 且 `Cache-Control: no-store`，没有用进程内数据伪装持久化。
- 非 `demo=1` 的 `/guide` 启动已经被代码阻断；当前候选路线只能进入全程标注“候选数据演示/非真实导航”的演示模式。旧的“候选路线可伪装成正式导览”结论已关闭。
- 游记提取已支持精确原文位置、明确停留时长、`EXPLICIT/ALIAS/FUZZY`、成组多候选、选择/排除及理由、未知片段、时间窗/行动约束逐项解决或明确忽略。原文不进入 URL；远程提取同时需要服务端能力开关和游客当次勾选同意，缺任一条件即不发送全文。
- `RoutePlan` 与 `VisitSession` 有严格本机 schema、修订、合法状态和失败关闭；会话恢复绑定 `planId + revision + validationCheckedAt + validationFingerprint`。分享已有最小字段预览、固定 7 天、损坏/到期阻断及同浏览器撤销。
- 前台连续定位必须由用户在进行中的显式 demo 手动开启；只展示精度、到下一候选点的直线距离和粗略方位。可靠精度、保守半径、连续样本和驻留门槛只会产生“可能已接近”，不会自动到点；低精度、拒绝、超时、切后台、暂停或结束会停止监听与语音，刷新不自动重启。
- AI 回答已直显 8 类事实标签、来源级别和项目核验状态；私有知识卡只保存问题与来源引用，不保存回答全文。版本化 GoldenSet 覆盖有源史实、传说边界、动态/安全拒答、提示注入与未知问题，但它仍不是管理方签发的生产 `QualityGate/ReleaseDecision`。
- Service Worker 已升级为 v3，核心清单、关键静态资产、API 不缓存、显式 `RETIRED=[v1,v2]` 清理以及 foreign/future cache 保留均有版本化测试；`DataControl` 会逐项报告本机存储/缓存清除失败。发布证据预检只可输出 `READY_FOR_SERVER_REVIEW`，永远不会在浏览器本地产生正式 `READY`。
- 后端切片已新增供应商中立的 PostgreSQL/PostGIS 初始迁移、校验和/advisory-lock 迁移器，以及最小化服务端分享的创建、读取、撤销领域/仓储/API。数据库只种入 `DRAFT` 景区根，分享只存 token hash、最小 JSON、到期/撤回和审计事件；公开部署未配置 `DATABASE_URL` 或可信登录，创建能力默认关闭。

- AC-01 至 AC-10 中 **0/10 完整通过**；AC-03/04/05/06/08/09/10 有局部自动化证据，AC-01/02/07 仍缺关键流程或正式责任数据。
- 正式边界、入口、内部路网、动态状态、官方求助渠道、现场复走、无障碍与弱网验证、文化/宗教审核和资产权利仍未取得；因此没有可生产消费的 `READY` 行程。
- 当前游客 UI、`/admin`、个人数据、云游进度、知识卡与既有分享仍主要使用 `localStorage`。虽然已有一个 PostGIS/ShareLink schema 与服务端分享 API 切片，但没有已配置/迁移验证的外部数据库、可信账号、对象级授权、完整不可变审计、游客端服务端分享接入、原子内容发布或生产 RAG/动态工具；发布准备度页面也只是证据结构预检。
