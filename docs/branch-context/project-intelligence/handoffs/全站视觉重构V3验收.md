## 2. 已完成范围

- 首页：品牌顶栏、左文案/右动态 Hero、禅小荔、四站候选路线、真实候选地图、偏好生成器与九种受控视觉预览。
- 地图：桌面地图工作台、左侧规划、右侧图层与工具、底部路线时间轴；手机地图优先与规划抽屉。
- 其余页面：路线规划、旅程、知识卡、云游、到达助手、现场导览、文化问答、账号、隐私、分享、治理台、发布准备度与地图编辑器全部纳入统一视觉系统。
- 统一设计：宣纸白、森林绿、路线金、克制朱砂；统一网格、标题、导航、表单、纸张面板、焦点态、空态与响应式间距。
- 动效：页面与章节入场、按钮/卡片反馈、地图标记与面板揭示、Hero 播放、禅小荔状态切换；同时支持减少动态、高对比、简化视觉与静音。
- 禅小荔：全游客页面可用，支持单击问答、长按语音、双击历史、拖动、收边与恢复；收边后的点击中心已保持在视口内。

## 5. 不得误解的边界

- 九种地图视觉中只有标准与禅意属于当前公开候选皮肤，其余七种明确标记“开发演示”。
- 地图中的本地 OSM 点位与路线仍是公开候选、未完成现场复走，不构成正式导航、ETA 或安全承诺。
- Hero 视频是已登记的 AI 概念媒体，不是景区实拍宣传片。
- 禅小荔当前是由十个透明动作资产驱动的 2.5D 状态角色，不是真正的 3D 骨骼模型；语音能力受浏览器权限和实现支持影响。
- 本轮交付为网页端和可安装 PWA 的响应式 App 体验，不是独立原生 iOS/Android 安装包。
