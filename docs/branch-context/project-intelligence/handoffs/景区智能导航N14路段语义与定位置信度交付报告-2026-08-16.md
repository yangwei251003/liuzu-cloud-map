# 景区智能导航 N14 路段语义与定位置信度交付报告

日期：2026-08-16  
结论：软件闭环完成；生产仍为 `NO_GO`

## 1. 修复的问题

逐向运行时此前基于整条路线折线的下一个坐标生成转向。道路曲线为贴合形状加入的中间点可能被误报为左转或右转；剩余距离又按整条几何比例缩放，无法正确表达各正式边独立发布的距离。地图虽显示蓝色当前位置，但没有把浏览器报告的不确定性范围画出来，也没有在停止指令时移除旧方向感。

## 2. 当前实现

- 当前定位投影先映射到正式 traversal；边内部坐标仅用于道路跟随。
- 下一转向只在当前正式边结束与下一正式边开始处计算；索道/观光车的上车、乘行、下车仍优先。
- 剩余距离等于当前边发布距离的剩余部分加后续边总量，进度由剩余距离反推；ETA 继续逐边计算。
- 浏览器报告的定位半径在设备内转换为 48 段闭合 WGS84 精度圈，异常、零值、越界或超过 2,000 米时不绘制。
- 精度圈和当前位置标记按可靠、待确认、停止三态显示蓝、金、红；非可靠状态隐藏旧方向箭头。读屏文本同时解释颜色与边界，颜色不是唯一信息。
- 当前点、精度圈和质量状态不上传、不缓存、不进入导航历史。
