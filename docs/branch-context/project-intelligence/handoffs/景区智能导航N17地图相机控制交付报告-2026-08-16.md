# 景区智能导航 N17 地图相机控制交付报告

日期：2026-08-16  
结论：软件闭环完成；生产仍为 `NO_GO`

## 1. 修复的问题

正式导航地图此前在每个可靠定位更新时执行回中。游客拖动查看前方路口、缩放确认换乘或旋转辨认方向后，下一次 GPS 会立即抢回视野，无法完成地图 App 的常见浏览任务。

## 2. 当前实现

- 相机模式分为 `FOLLOWING`、`BROWSING` 和 `OVERVIEW`，转换由纯函数约束。
- 只有模式为自动跟随、位置有界且导航质量为可靠/到达时，GPS 才能移动相机。
- 真实拖动、缩放或旋转进入手动浏览；程序自身的回中/总览动画不误触发手势状态。
- 剩余路线总览只读取 N16 的未完成几何；连续定位可继续更新路线和蓝点，但不会抢回视野。精确到达时只定位正式终点。
- 只有游客显式点击“回到当前位置”且当前定位可靠时才恢复自动跟随；低精度、定位不可用或指令停止时按钮禁用。
- 模式有可见文字与读屏 live 状态，按钮满足 44px 触控高度，动画遵守减少动态偏好。
- 相机模式、中心、缩放和旋转均只在设备组件内存，不进入 API、CacheStorage、导航历史或日志。
