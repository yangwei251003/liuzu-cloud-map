状态含义：

- `TRACEABLE`：所要求的蓝图层映射存在；仍只是设计证据，测试尚未执行。

- `DOCUMENT_GAP`：至少一个指定层没有明确证据；本版复核结果为 0 项，若后续源文档变更再重新登记。
- 本矩阵所有测试均为“计划测试”，不存在 `PASS`；所有 Sprint 均为 Gate 2、六项准备度和开发授权通过后的相对计划。
