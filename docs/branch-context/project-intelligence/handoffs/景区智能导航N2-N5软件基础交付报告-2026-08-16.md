在 N1 正式多策略路由基础上，已完成逐向导航运行时、签名离线包安装与本地规划、好友同行位置共享、确定性 AI 个性行程、管理端候选属性编辑、N5.1 自动定位与沿途社区收口、N5.2 账号级导航历史、N5.3 正式离线运行链、N5.4 验签离线矢量地图/POI 安全渲染、N6 GIS 候选版本化提交与职责分离审核，以及 N6.1 GIS 专业审核工作台。所有正式能力继续依赖当前发布快照；缺官方数据、真身份、真库、有效运营状态或签名包时失败关闭。

## 主要交付

- `/guide`：既有定位授权下自动执行一次高精度节点匹配；蓝色正式路线、当前位置/方向箭头、剩余距离/时间、下一步动作、暂停/恢复/退出、偏航与到达确认、运营版本变化重算。
- 沿途与社区：只显示本次 traversal 道路链上、前方 120 米走廊内且游览证据完整的正式 POI/设施；社区按景区隔离，只展示绑定当前正式 POI 的 24 小时审核动态、照片和打卡摘要，不传游客 GPS。
- `/api/v1/scenic-itineraries`：只接受时长、兴趣、同行、节奏、难度和通行方式等结构化约束；用正式路网确定性组合多站路线。
- `/api/v1/travel-groups/*`：建队、邀请、接受、开始/停止共享、覆盖式位置更新和成员位置读取；真库/会话/开关缺一项即不可用。
- 离线：完整发布链 API、ECDSA P-256 签名清单、规范化清单哈希、唯一资产角色、逐资产流式 SHA-256/长度/类型、隔离候选缓存、全通过后原子活动登记、PMTiles Range、同引擎本地规划，以及同包无网络样式/矢量瓦片/点状 POI 渲染；当前无正式生产包，不缓存候选 GIS。
- `/admin/map-editor`：候选入口、道路、景点、设施、推荐路线和边界，以及道路/游览属性；可主动提交不可变候选版本进入专业审核。提交与审核 API 要求可信边缘身份、OIDC/MFA、租户角色、幂等键和独立审核人；审核通过仅为待正式化，仍不直接发布。
- `/admin/gis-review`：同租户待审队列、不可变详情、摘要复核、候选空间预览、逐对象来源/属性、职责分离状态、HTTPS 证据和批准/退回；提交人相同会禁用并由后端拒绝，终态持续显示“待正式化、尚未发布”。
- `/api/v1/navigation-sessions`：服务端重放并核对当前正式路线，按幂等键和 revision 记录开始、暂停、恢复、重算、到达与退出；只保存 50 米剩余距离档位，不接收坐标、路线几何、朝向或轨迹。`/account` 提供私有历史，数据导出和账号删除同步覆盖。
- 数据库：`006_formal_offline_navigation_packs.sql`、`007_travel_group_live_location.sql`、`008_formal_scenic_itineraries.sql`、`009_formal_place_communities.sql`、`010_navigation_session_lifecycle.sql`、`011_gis_draft_review_workflow.sql` 及同名补偿脚本。第九号迁移不回填旧候选社区，第十号不把旧会话自动提升为新契约，第十一号不把审核候选直接提升为正式 GIS。
