# 景区智能导航 N13 确定性自动重路由交付报告

日期：2026-08-16  
结论：软件闭环完成；生产仍为 `NO_GO`

## 1. 本次关闭的软件缺口

此前运行时能够识别连续偏航、正式路网版本变化和运营版本变化，也会停止旧导航会话，但游客仍需手动重算；版本变化时手动路径可能继续使用界面缓存的旧快照。N13 将三种事件统一为受约束的自动重路由，并保持“无安全结果即继续停止”。

## 2. 实现边界

- 偏航仍需三个可靠样本通过滞回；版本变化仍需完整快照监控确认。
- 重算前停止旧逐向指令和定位监听，导航会话先记录 `REROUTE_REQUIRED`。
- 仅接受 10 秒内、精度不高于 35 米的设备内样本；以“最近正式节点距离 + 精度不超过 80 米”保守贴合正式节点。
- 路线意图只含景区、起终节点、原策略/优化/显式偏好和期望版本；不含坐标、精度、时间戳、轨迹、朝向或几何。
- 线上重取完整当前快照；离线只允许重新校验通过且仍有效的活动验签包。两者复用同一确定性图算法。
- 新路线必须具有不同指纹，并精确匹配景区、起点、原目的地、路网版本、运营版本、策略、优化与偏好。正式版本变化还需通过运营重算判定。
- 成功后才切换路线并记录 `REROUTED`；任何失败保持停止，转现场标识或工作人员，不调用候选 GIS 或未经批准的外部路线。
