# 用户需求与游客行为分析

状态：`READY_FOR_GATE_1_REVIEW`  
研究截止：2026-08-14（Asia/Shanghai）  
阶段边界：本报告只形成证据、假设和 Gate 1 选项，不替用户确定核心客群或 MVP。

## 0. 结论摘要

1. **目前最强的客群证据只适用于特定春节假期。** 2026 年春节 9 天，官方初步统计称六祖故里旅游度假区约接待 58.5 万人次，年初五约 11.4 万人次；广州、佛山、阳江、江门等周边城市短途自驾为主，县外游客超七成。[LZ-017] 这证明节假日自驾和高峰分流重要，但不能定义全年主用户。
2. **高铁开通新增了“无车自由行”场景。** 2025-12-22 新兴南站启用，并开通连接国恩寺等区域的 3 条接驳公交专线。[LZ-015] 因班次、换乘和站点仍属持续优化对象，[LZ-016] 行前信息与最后一公里仍需一手测试。
3. **“祈福/文化理解 + 安静休闲 + 温泉住宿”是重复出现的体验组合。** 官方将禅文化、温泉、乡村民宿共同组织成文旅产品；国恩寺与周边酒店平台内容中也重复出现祈福、温泉、安静、家庭和短住信号。[LZ-007][LZ-010][LZ-C02][LZ-C04][LZ-C05] 这是中等强度信号，不等于所有游客都有宗教信仰或愿意住宿。
4. **用户最大的潜在困难不是“景点不够多”，而是范围、状态和解释不可靠。** 六祖镇、4A 景区、国恩寺及扩展点位容易混淆；开放、停车、公交、步道与商户信息动态变化；游客评论还大量复制景点介绍并混入传说。[LZ-001][LZ-008][LZ-C01][LZ-C02]
5. **无障碍、弱网、真实步行路径和普通工作日行为几乎没有公开证据。** 银发、轮椅、婴儿车、听视障用户不能被宣传语代替，必须现场研究。
6. **景区管理者和内容审核者也是核心用户。** 若没有可追溯的更新、审核和应急发布流程，面向游客的“实时”“AI讲解”能力不可持续；既有信息化项目的绩效问题也证明应先盘点、再建设。[LZ-023]

### 1.2 公开 UGC 的偏差

- 景点评论存在明显复制官方/百科式介绍的现象，部分年份、人物和文保表述互相矛盾。[LZ-C01][LZ-C02]
- 平台“热门提及”“真实住客”等标签属于平台机制，不是独立研究抽样。
- 高分用户、内容创作者、平台分发和商户营销会造成选择偏差。
- 旧评论受疫情、旧收费和旧设施影响，不能当作当前状态。
- 单条“停车贵”“疑似诱导消费”等评论只可登记为调查线索，不可直接指控运营方。[LZ-C03]
- 本轮没有抓取登录后私域内容、没有绕过平台限制，也没有下载用户图片。

### 1.3 证据强度定义

- **强：** 一手/官方数据直接支持，且结论严格限定在其时间和口径内。
- **中：** 多个不同来源或多条近年评论出现同一模式，但缺少概率抽样。
- **弱：** 少量、旧或单一平台线索，仅用于提出问题。
- **未知：** 公开证据不足，必须访谈、观察或现场测量。

## 5. 高频痛点与机会排序

### P0：若不解决就不应上线核心体验

1. **错误范围与入口。** 用户可能把镇、景区、寺院和扩展商业点混为一体；必须使用正式边界和入口级 POI。
2. **动态信息失效。** 开放、公交、停车、步道、活动和封闭需要责任数据源、更新时间和降级文案。
3. **史实/宗教传统/传说混写。** 必须以命题级来源和审核状态约束 AI，不允许从 UGC 补全事实。
4. **高峰与异常安全。** 客流、分流、天气、道路/步道关闭、走失和急救需统一状态与离线兜底。
5. **宗教与文保空间打扰。** 国恩寺核心区默认静音，位置触发、拍摄、游戏化和推送需获得明确许可。

### P1：决定产品是否真正可用

1. 自驾与高铁两种到达方式的差异化计划；
2. 核心区与扩展点位的时间/交通成本；
3. 老人、儿童、轮椅和婴儿车的真实连续路径；
4. 短讲解、深讲解、礼佛模式、亲子模式的节奏；
5. 管理方快速更新与内容审核工作台；
6. 与既有信息系统的数据复用，避免重复建设。

### P2：证据不足、可延后

- 完整 UGC 社区、排行榜和社交关系；
- AR、全 3D、完整游戏和强打卡任务；
- 自动商业推荐与全镇商户交易；
- 未取得宗教/文保许可的语音自动触发；
- 用“AI懂你”替代真实问卷、访谈和可用性测试。

## 6. MVP 核心用户与场景选项

### 选项 A：核心文化区独立游客的现场风险验证切片（初步推荐）

- **用户：** 自驾或高铁到达、希望在有限时间内完成国恩寺及相邻核心节点体验的个人/家庭。
- **最小闭环：** 选择到达方式 → 核验开放/交通/停车 → 到正确入口 → 看清核心区真实地图 → 获取分层文化讲解与礼仪 → 异常时收到安全信息 → 保存足迹/知识卡。
- **理由：** 能同时覆盖最强到达证据、核心文化价值和高风险信息问题，范围相对可控。
- **门槛：** 核心区正式边界、路径、寺院规则、设施、内容审核和运营数据源必须到位。

该切片不是完整价值 MVP。完整候选闭环还应保留“有权处理的游记/需求 → POI 消歧与用户确认 → 真实路线执行 → 到点讲解 → 轻量打卡 → 保存/私有或链接分享”。若只做上述现场切片，应把它命名为 PoC，并由用户明确接受暂不验证游记转行程和分享差异化。

### 选项 B：两天一夜“禅文化 + 温泉”游客

- **用户：** 周边城市夫妻、朋友或家庭，计划住宿并组合国恩寺、温泉与餐饮。
- **价值：** 与官方业态和住宿 UGC 模式吻合，可能提高停留和消费。
- **风险：** 商业库存/价格、温泉合规、广告公平和跨点交通使首版复杂度显著增加。

### 选项 C：六祖文化深度/研学用户

- **用户：** 信众、文化游客、研学团队、导游与教师。
- **价值：** 能突出内容深度和地方独特性。
- **风险：** 对文保、宗教、史学审核和团队管理要求最高，不适合在内容体系未完成前自动生成。

**建议：** Gate 1 优先批准/否决“选项 A 作为首轮验证对象”，B/C 保留为后续可扩展场景；这不是产品定案。

## 7. 成功指标假设（不等于已确定 KPI）

| 目标 | Discovery/原型可测指标 | 上线后才可测指标 |
|---|---|---|
| 找到正确入口 | 任务完成率、首次点击正确率、求助次数 | 错误导航/投诉量、入口改道率 |
| 信任动态信息 | 用户能说出来源与更新时间；不确定状态理解率 | 旧信息事故率、运营更新及时率 |
| 理解文化分层 | 事实/传统/传说辨识正确率；内容满意度 | 误传投诉、审核退回率、深度内容完成率 |
| 尊重宗教空间 | 静音/拍摄规则理解率 | 现场干扰投诉、违规提醒次数 |
| 安全完成核心体验 | 异常任务成功率、离线安全卡可发现性 | 走失/封闭误导/应急升级时效 |
| 降低运营负担 | 更新一条状态所需步骤和时间 | 重复咨询量、跨部门信息不一致数 |

所有指标需要景区、寺院和用户共同确定基线，不能把“停留越久、点击越多”默认当成功；在禅意/宗教体验中，少打扰可能比高互动更好。

## 8. 后续一手研究计划

### 8.1 现场观察

至少覆盖以下四种时段，避免只看节假日：

1. 普通工作日；
2. 普通周末；
3. 六祖诞/春节/香荔季等高峰活动（在审批与安全允许下）；
4. 雨天或高温天气；极端天气不安排研究人员冒险，只复盘运营记录。

每次记录：到达方式、入口选择、停车/候车、问路点、停留点、回退、厕所/休息、讲解使用、拍照、儿童/老人协助、跨点交通、异常与离开方式。只做匿名计数，不采集人脸或宗教行为身份。

### 8.2 半结构访谈建议样本

| 对象 | 建议首轮数量 | 关键问题 |
|---|---:|---|
| 自驾游客 | 8—12 组 | 从哪里出发、如何选入口/停车、最怕什么信息失效 |
| 高铁/公交游客 | 6—8 组 | 班次、换乘、行李、支付、返程和备选交通 |
| 礼佛/文化游客 | 8—10 人 | 参访顺序、礼仪、安静、内容深度、禁忌和信任来源 |
| 家庭游客 | 6—8 组 | 儿童节奏、厕所、休息、走失、讲解与婴儿车 |
| 银发/行动不便用户 | 6—8 人（含陪同者） | 坡度、台阶、座椅、字体/语音、求助和轮椅连续性 |
| 徒步/自然游客 | 4—6 人 | 难度、天气、补水、网络、封闭与救援 |
| 景区/游客中心/交通/安保 | 每类 2—4 人 | 状态更新、峰值、投诉、应急、数据归属与跨部门协同 |
| 寺院/文保/非遗/地方史审核者 | 每类 1—3 人 | 内容分层、可讲/不可讲、拍摄/声音/活动边界 |
| 导游/研学教师/创作者 | 每类 3—5 人 | 内容组织、团队节奏、引用与素材许可 |
| 酒店/民宿/餐饮/果园 | 每类 3—5 家 | 营业数据、预约、接驳、季节性、广告与更新能力 |

数量是首轮饱和度目标，不是统计代表性样本。

### 8.3 拦截问卷

在取得景区同意后，分别于工作日、周末和活动日收集不少于 100 份有效样本，核心字段包括：常住城市、到达方式、同行结构、首次/复访、主要目的、计划时长、最需要的信息、实际问路/绕路、停车/公交、讲解偏好、无障碍需求、是否住宿及后续点位。避免询问宗教信仰等非必要敏感信息；“来礼佛/祈福”可作为自愿选择的旅行目的。

### 8.4 任务型可用性测试

在 Gate 1 通过且进入蓝图阶段后，用低保真原型测试：

- “明天从广州坐高铁来，找到可核验的国恩寺接驳和返程方案”；
- “带一位行动慢的长者，从停车到核心点，判断是否适合”；
- “区分一个史实、一个宗教传统和一个民间传说”；
- “发现步道临时关闭并选择安全替代”；
- “运营人员在 3 分钟内更新开放状态并留下来源与审批记录”。

### 8.5 数据与伦理

- 不采集人脸、精确宗教行为、未成年人身份或不必要位置轨迹；
- 录音、拍照、引用必须取得明确同意；宗教仪式和文保敏感区按管理方规则执行；
- 对商户不做付费排名暗示，赞助/广告与官方服务明确区分；
- 研究数据设保存期限、访问权限和匿名化规则。

## 9. Gate 1 前必须由用户/项目方确认

1. 首轮核心用户是否采用选项 A，还是将住宿/研学提前；
2. 首版体验边界是核心服务区还是扩展“禅意之旅”；
3. 是否能获得景区、国恩寺、交通、文保/非遗和既有数字系统负责人配合；
4. 能否安排普通日、周末和一次高峰日的现场研究；
5. 用户方 Logo/IP 是否允许在宗教/文保语境中使用，以及使用边界；
6. 对定位、未成年人、无障碍、语音和分享数据的隐私边界。

在这些问题回答前，本报告不会把“周边自驾家庭”“礼佛用户”或“两天一夜温泉客”写成唯一核心用户。
