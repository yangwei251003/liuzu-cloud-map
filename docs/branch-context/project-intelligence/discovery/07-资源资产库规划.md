## 1. 结论先行

当前项目已经有“品牌方向与技术能力线索”，但还没有足以开工的生产资产包：

- 两张本地品牌图均为扁平 RGB PNG、无透明通道，不是矢量/分层生产文件；权属和公开使用许可未确认。
- 官方网页已经提供文化、建筑、景观和物产研究线索，但网页公开不等于图片/视频可商用；本轮未下载任何许可不明媒体。
- 高德与 Gemini 只确认了环境变量名已配置，未验证配额、条款、地区、数据权利或是否最终选用。
- 路线、景区内部道路、设施、触发点、开放信息、讲解脚本、实拍照片、语音与弱网包尚未形成经审核版本。
- 字体、图标和开放地图有许可清晰的候选来源，但尚未锁定具体版本，也不能在 Discovery 阶段提前选型。

因此，Gate 1 可以审核“需要什么、从哪里合法取得、哪些必须实拍/授权、哪些延后”，但不能把当前项目误判为 Implementation-ready。

## 2. 资产治理目标

资产库不是“把能找到的素材下载回来”，而是确保任何进入产品的文件或数据都能回答：

1. 它是什么、用于哪个景区/页面/路线/POI？
2. 来源和权利人是谁？
3. 允许研究、商用、改编、公开部署、再分发和 AI 处理中的哪些行为？
4. 是否需要署名、同许可、地域/期限/媒介限制、人物/场地产权同意？
5. 哪个版本、何时取得、原文件和衍生文件如何关联？
6. 是否经过事实、文化、视觉、隐私、安全和现场验证？
7. 过期、撤权、投诉或版本升级时如何下架与替换？

## 3. 状态模型与门禁

### 3.1 资产状态

| 状态 | 定义 | 可做 | 不可做 |
|---|---|---|---|
| `DISCOVERED` | 找到来源线索 | 保存 URL、标题、发布者、日期与研究备注 | 下载、设计引用、公开展示 |
| `REFERENCE_ONLY` | 可用于内部研究但许可不明/受限 | 分析母题、列拍摄清单 | 进入产品、描摹、改编、再分发 |
| `LICENSE_REVIEW` | 已找到许可证/合同但未审核完 | 法务/项目负责人核对条款 | 对外发布 |
| `CLEARED` | 权利范围与条件已书面确认 | 在许可范围内制作衍生版本 | 超范围、超期限或省略署名 |
| `PRODUCTION_READY` | 权利清晰且技术/内容/视觉验收通过 | 进入版本与发布流程 | 绕过版本、审核或追溯信息 |
| `REJECTED` | 权利、质量、真实性或风险不合格 | 保留拒绝原因和替代建议 | 再次混入候选库 |
| `REVOKED/EXPIRED` | 授权撤回或到期 | 下架、替换、保留审计记录 | 继续公开使用 |

### 3.2 关键规则

- 国家版权局相关倡议明确“先授权、后使用；无授权、不使用”（CVA-025）；网页公开可见不能推导出复制、改编或信息网络传播权（CVA-024）。
- 政府、景区、媒体和社交平台图片若无明确开放许可，一律 `REFERENCE_ONLY`；只保存链接、描述和拍摄/授权需求。
- “可商用”不是完整许可记录。必须保存许可证版本、版权声明、作者、原始 URL、获取日期、署名格式和改编/再分发条件。
- CC 素材逐项判断：BY 要署名，SA 有同许可要求，NC 不可用于商业项目，ND 不可公开改编版（CVA-031）。
- AI 生成内容不是“无版权、无规则素材”。对外发布的生成文本、图片、音频、视频等要按现行办法落实显式与隐式标识，不得删除或隐匿标识（CVA-026）。
- 地图截图、瓦片、POI、路线和坐标不能在不同供应商间随意复制。即使采用 OSM，也要遵守 ODbL 署名/同许可与服务策略，并另行满足中国境内测绘与坐标合规（CVA-027）。

## 6. 分类别资源规划

### 6.1 地理、地图与 POI

必需资产：

- 景区/体验范围、入口、出口、道路、步行路径、桥/台阶/坡度/不可通行区；
- 景点、厕所、游客中心、停车、餐饮、休息、无障碍、急救、消防/求助等设施；
- 每个 POI 的标准名、别名、坐标、入口点、类型、开放/核验状态、更新时间和权威联系人；
- 候选路线轨迹、距离、预计时间、方向、难度、停留点和触发点；
- 普通底图与主题图层的权利、署名和缓存/离线边界。

优先来源：景区/主管部门提供的权威数据与现场测量；合规地图服务用于底图、定位和路径；其他开放数据只作交叉验证。不得从其他地图截图、描路或批量抄 POI。

进入 `PRODUCTION_READY` 前：坐标/入口需多源与现场核验；路线需实走；设施和开放信息有责任主体、采集日与复核频率。具体技术选择由 GIS 报告和 Gate 1 决定。

### 6.2 文化知识与讲解

必需资产：

- 六祖惠能、国恩寺、相关历史脉络、建筑与地方文化的可引用资料；
- “历史事实 / 宗教传统 / 民间传说 / 当代营销 / 创作演绎”五类标签；
- 每条讲解的事实原子、来源、适用 POI、受众、时长、审阅状态、禁止推断与可追问边界；
- 礼仪、安静区域、拍摄限制、节庆/活动、开放信息的权威更新渠道；
- 中文与未来多语种的术语表、专名读音和人工审校。

六祖传说已被国家非遗平台归为民间文学（CVA-020），因此故事可以成为内容资产，但必须显式标“传说”，并确认具体讲述文本、改编、录音和保护单位相关授权。

进入 `PRODUCTION_READY` 前：事实来源达到要求；文化/宗教审核人签字；脚本经过路线实走与时长测试；实时信息不能固化在长期音频里。

### 6.3 图片

首选顺序：

1. 项目方/景区自有并能书面授权的原始照片；
2. 委托摄影，合同明确商用、改编、长期公开部署、媒体范围、原片和人物/场地权利；
3. 正规图库逐项购买，保存发票、许可范围和下载凭证；
4. 许可清晰的开放素材逐项审计与署名；
5. AI 生成只用于无法实拍的解释性插画，不能伪造景点现状。

拍摄清单至少覆盖：景区环境、入口/方向、建筑远中近景、细部、古荔树与季节、山水/步道、服务设施、无障碍与安全、游客使用情境。每个重点 POI 建议包含“环境定位、主体识别、细节讲解”三类照片；数量在蓝图阶段按首发 POI 数量计算。

政府文章中的“某单位供图”只说明供图主体，不自动授予本项目商用/改编/再分发权。没有明确许可时只留页面 URL。

### 6.4 视频

候选用途：景区选择页短片、路线预览、建筑/物产细节、云游章节、使用教学。MVP 不以宣传片或无人机大片替代真实地图。

进入生产前需确认：脚本、场地/寺院拍摄许可、人物与未成年人同意、无人机与空域/现场管理要求、音乐/字体/素材许可、横竖版裁切、字幕、静音可理解性和 AI 标识。政府/平台宣传视频一律不下载复剪，除非获得明确授权。

### 6.5 音频、音乐与语音

资产拆分：

- POI 讲解、人声提示、方向/偏航/到达等短提示；
- 环境声、音乐与转场声；
- 试听用 TTS 与正式发布语音；
- 中文专名/粤语或其他语言读音表、字幕/逐字稿。

权利要求：真人配音合同需覆盖声音录制、编辑、合成/克隆是否允许、商用、渠道、期限、地域和撤回；TTS 供应商需核验输入数据、输出使用、存储、地区、费用与音色权利；音乐/环境声逐条许可。未经单独明确授权，不用真人录音训练或克隆角色声音。

VoiceMap 的官方生产经验表明，编辑期可用 TTS 反复试听，并应让讲解时长匹配行走时长；GPS 自动播放还需离线和现场测试（CVA-015、CVA-016）。这只是流程参考，不代表选用 VoiceMap。

### 6.6 字体与图标

- 正文候选使用高可读中文无衬线；文化标题可评估思源宋体等 OFL 字体。正式引入时锁定版本、保存许可证、版权声明、哈希和子集化/修改方式（CVA-028、CVA-029）。
- 不从 Logo/海报图片中抠字当字体，也不以“网上说免费商用”作为授权证据。
- 通用 UI 图标可评估 Lucide；主体为 ISC，部分源自 Feather 为 MIT，发布包需保留相应声明（CVA-030）。
- 景区专属建筑、古荔、藏佛坑和文化类型图标由项目原创/委托，以获授权照片或现场观察为基础。
- 公共设施、安全和无障碍图形应遵循相关公共信息图形规范，不为追求“IP 化”改变含义。

### 6.7 Logo、IP、纹样与动效

需向设计方索取：

- Logo：AI/SVG/PDF 等矢量源稿、图形标、字标、横/竖版、单色/反白、透明 PNG、色值/色彩空间、字体/字形来源、最小尺寸、安全区、禁用示例；
- IP：分层源稿、转面、比例、线稿、色板、表情、口型、手势、动作、道具、服饰/经卷说明、角色文案与禁用姿态；
- 动效：源工程、逐帧/矢量导出、循环/一次性规则、透明通道、减少动态替代、声音拆分及所有插件/素材许可；
- 权利文件：设计合同、作者/公司授权、商标和第三方字体/素材清单、商用/改编/公开部署/再分发/多景区复用范围。

AI 参与角色、纹样、动效或宣传图生成时，登记模型、版本、日期、提示词/参考图权利、人工修改、相似性审查和发布标识（CVA-026）。不得用许可不明的在世艺术家/知名 IP 作为风格复刻目标。

### 6.8 3D、AR 与沉浸资产

当前建议：MVP 延后，不作为 Gate 1 生产准备的阻塞项。

若未来启用，需新增：地形/建筑/角色模型、材质、骨骼/动作、LOD、碰撞、空间锚点、设备性能、场地许可、文物/建筑测绘或摄影测量许可、模型版权和安全提示。LB/T 097-2025 强调所在地文化、原创/IP、技术与成本匹配、不同群体、无障碍、指引、安全、隐私和网络保障（CVA-003），因此“有 3D/AR”本身不是通过条件。

## 7. “游记转行程”的内容权利策略

该能力不仅是技术解析，还会处理第三方文字、图片、链接和个人信息：

- 用户上传前应确认其拥有或获得必要权利，并清楚知道解析、保存、分享和公开发布范围。
- 对第三方文章/社交链接，不绕过登录、付费墙、反爬或平台保护，不默认抓取/永久保存全文与媒体。
- 将“来源内容”“提取的地点候选”“核验后的 POI/事实”“用户行程”分开保存，并保留来源 URL 与时间。
- 公开分享时尽量展示用户自己的结构化行程与短引用/链接，不复制原文、图片或视频；具体引用范围需经版权审核。
- 导游/机构内容进入官方推荐前，合同明确文字、照片、语音、路线创意、角色故事、改编、AI 处理、收益、署名、版本更新和下架权。
- 普通游客 UGC 在第一版建议默认私有或链接可见；开放社区、公开推荐与商业售卖会显著扩大审核、隐私和版权义务，必须单独确认。

## 8. 建议的存储与版本结构（蓝图候选，不在 Discovery 创建产品目录）

```text
assets/
  owned/            # 项目/景区自有且权利清晰的原始文件
  licensed/         # 逐项有许可证或采购凭证
  commissioned/     # 委托制作及合同/交付物
  generated/        # AI生成及提示词、模型、标识记录
  reference-links/  # 仅URL和研究备注，不放许可不明媒体
  releases/         # 人物、声音、场地、无人机等授权书
  manifests/        # 机器可读资产清单与哈希
  derived/          # 从已许可原件产生的裁切、转码、缩略图
  rejected/         # 只留拒绝原因与元数据，不保留违规副本
```

原则：原始文件只读保存；衍生文件不能覆盖原件；每次发布锁定 manifest；许可证/合同与资产版本绑定；外部撤权可以按 Asset ID 一键定位影响范围。

## 9. 获取计划与责任建议

### 9.1 Gate 1 前（当前阶段）

Gate 1 要求用户确认方向与缺口闭合计划，不要求此时已经取得全部生产级资产。正式权利文件、可发布 GIS 数据、媒体和现场核验继续作为 Implementation 硬阻塞。

| 任务 | 建议责任方 | Gate 1 所需结果 |
|---|---|---|
| 处理 Logo/IP 权属、VERSION A 定稿与使用范围 | 用户 + 原设计方/权利人 | 确认当前仅作内部参考，并指定取得书面权利、第三方素材清单和源文件的责任/时点 |
| 向景区/文旅方发出数据与媒体清单 | 用户/项目方 | 确认可联系的主体、请求范围和预计路径；不要求 Gate 1 前已收到全部文件 |
| 明确首发体验边界与重点 POI | 用户 + Discovery 审核 | 批准首发/延后范围及未知项进入蓝图的依赖清单 |
| 确认政府网页媒体只作参考 | 项目负责人 | 批准版权规则；许可不明媒体不进入生产 |
| 选择视觉候选方向 | 用户 | 方向 A/B/C 或组合，用于下一阶段设计蓝图 |
| 明确 3D/AR 是否延后 | 用户 | 锁定 MVP 范围边界，不授权制作或采购 |

### 9.2 蓝图阶段（Gate 1 通过后）

- 形成每类资产精确规格、数量、命名、尺寸、语言、预算、责任人和验收标准；
- 决定地图、AI、语音、存储候选服务并完成技术/费用/条款比较；
- 制定现场采集、摄影/视频/音频制作、文化审校、无障碍和真机测试计划；
- 把许可证、授权书、生成标识、哈希和发布 manifest 纳入工作流。

### 9.3 Implementation 开工前

至少满足：

- Logo/IP 的正式源稿和权利文件齐全；
- 首发 POI、路线、入口、设施和触发点达到核验要求；
- 每个首发 POI 有可发布照片或明确的无图替代；
- 首发讲解脚本有来源、文化审核、逐字稿与授权语音；
- 字体、图标、地图、音乐/音效、API 条款和署名方案锁版本；
- 标准地图/无 IP/静音/减少动态/弱网降级资产齐全；
- AI 生成资产的显式/隐式标识链路已设计并验证；
- 可按 Asset ID 追踪、下架与替换。

## 10. 项目方/景区方资料请求清单
