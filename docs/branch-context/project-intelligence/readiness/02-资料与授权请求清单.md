# 开工前资料与授权请求清单

状态：`READY_FOR_PROJECT_OWNER_ROUTING`  
日期：2026-08-14（Asia/Shanghai）  
说明：本文件只列需要谁提供什么；不表示已经联系任何机构或取得授权。

## 1. 可由项目方直接放入工作区的资料

### A. 景区与空间数据包

- 正式首发范围与管理边界；
- 每个正式入口、停车/接驳点、游客中心、厕所、医疗/安保/求助设施；
- 景区内部道路、台阶、坡度、无障碍段、门禁、封闭和危险区；
- 坐标系、数据格式、版本、采集日期、许可和责任人；
- 既有纸质/电子地图、导览图和路线资料。

### B. 运营与既有系统包

- 官网、公众号、小程序、导览、停车、闸机、广播、客服和应急系统清单；
- 每个系统的产权、合同、供应商、接口、账号、部署地域、运维和安全现状；
- 开放、停车、接驳、活动、封闭、客流和应急信息的权威来源与更新 SLA；
- 运营编辑、审核、发布管理员、应急发布和审计的主/备责任人。

### C. 文化与场所规则包

- 六祖、国恩寺、建筑、人物、非遗、地方史、传统与传说的可公开资料；
- 寺院/文保/非遗/地方史审核人；
- 拍摄、录音、播放、定位触发、IP 出现、儿童/无障碍和活动期间的书面规则；
- 每条资料的许可、可改编/翻译/生成音频范围与有效期。

### D. 品牌与资产包

- Logo 与“禅小荔”是否定稿；
- 矢量、透明底、分层源文件；
- 权利人、商标/版权、商用、改编、公开发布、多景区、地域与期限授权；
- 图片、视频、音频、字体、图标、地图样式和第三方素材清单。

### E. 合规与预算包

- 法务、隐私、安全、地图合规和内容审核负责人；
- 数据处理地域、保留/删除、未成年人、生成式 AI 标识和事故响应要求；
- 一次性 PoC、每月运营、峰值和退出预算上限；
- 采购审批人、合同签字人和供应商管理责任。

## 2. 仍需用户另行授权的行动

| Authorization ID | 行动 | 当前状态 | 未授权时处理 |
|---|---|---|---|
| AUTH-EXT-01 | 代表项目联系景区、寺院/文保、政府、既有 IT 或供应商 | `NOT_AUTHORIZED` | 只整理待询问题和公开资料 |
| AUTH-FIELD-01 | 现场采集、实走、拍摄、访谈或用户研究 | `NOT_AUTHORIZED` | 只保留计划，不模拟现场事实 |
| AUTH-POC-01 | 编写任何受限技术 PoC 或运行项目代码 | `NOT_AUTHORIZED` | 只做无代码证据和方案比较 |
| AUTH-API-01 | 调用可能计费、消耗配额或处理真实数据的外部 API | `NOT_AUTHORIZED` | 不调用；已有 key 不代表授权 |
| AUTH-ENV-01 | 安装依赖、建库、搭环境、部署或开通云资源 | `NOT_AUTHORIZED` | R-ENV 保持 RED |
| AUTH-PROC-01 | 询价、签约、采购或付费 | `NOT_AUTHORIZED` | 只形成容量模型和问题清单 |

## 3. 建议优先顺序

1. 项目方先提供 A–E 中已经掌握的文件和具名联系人；
2. 我方按证据台账核验格式、版本、权利和缺口；
3. 再由用户决定是否授权 `AUTH-EXT-01` 发出定向资料请求；
4. 正式数据和书面条款到位后，再判断是否确有必要申请现场或代码 PoC；
5. 不在资料不足时通过编码“先试试看”替代真实准备。
