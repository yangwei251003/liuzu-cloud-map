## DEC-0005 执行解释

- 用户明确表示此前需其授权的事项均同意，并要求尽快开发完整网站/App，构成第三阶段的明确开发授权。
- 原六项准备度台账继续作为未来生产发布检查表，不再阻塞本地可运行原型。
- 原型门槛：已批准蓝图、秘密文件已被忽略、技术栈可本地构建、GIS 数据具备来源/许可/坐标系记录、未知事实明确标为候选或待核验。
- 可逆技术选择由 Codex 自主决定；新增付费与生产级外部承诺仍不在本次授权内。

## DEC-0006 执行解释

- P0 代码整改以“失败关闭、可审计、可回滚”为优先，不以模拟数据、旧截图或单元测试伪造生产放行。
- 正式路网、封路、入口、运营发布及紧急渠道必须来自已审核、未撤回、在有效期内且已现场核验的发布快照；缺少任一证据时内部导航拒绝生成路线。
- 最终放行由 12 条版本化规则和 38 个场景证据共同判定。任何 `MISSING`、`BROKEN`、`MOCK`、`UNVERIFIED` 或外部阻断均为非零门禁和 `NO_GO`。
- 外部法务、许可、官方数据、真机现场、生产身份/数据库/告警/备份与供应商条款仍须由项目方完成，不能由本决定或代码替代。

- `OPERATIONS_REVIEWER` 必须与编辑人使用不同 OIDC subject，并在快照、路网和有效期仍一致时确认或拒绝。提交、复核与依据进入追加审计，同一路段同时只允许一项待复核观测。
- 确认观测不直接修改游客路线。N8 发布链服务器选择每条边最新有效确认观测，连同管制事件覆盖编译全路网，保存精确观测 ID/SHA-256；待审、新增、到期、哈希或基础版本漂移都会停止发布。
- 只有独立 `RELEASE_ADMIN` 原子发布的新运营快照能被路线引擎采用。游客端逐段显示实际客流、天气和倍率并说明已计入 ETA；UGC 数量、照片热度或游客 GPS 不能作为该观测的替代来源。
- 第十六号迁移和真库探针只建立工作流与验证虚构数据，没有插入六祖镇真实客流或天气。正式来源责任、校准/代表性、异常值、更新 SLA、真 PostGIS、生产身份及现场真机完成前保持 `NO_GO`。

## DEC-0023 执行解释

- `OFF_ROUTE` 必须先经过现有三点滞回，路网/运营 version 变化必须先由完整快照监控确认；两者都会先停止旧指令和定位监听，再进入自动重算，不能在后台静默继续引导。
- 重算只接受 10 秒内、精度不高于 35 米的设备内样本，并以“最近正式节点距离 + 定位精度不超过 80 米”进行保守节点匹配。服务端只收到节点 ID、策略、优化、显式偏好和精确版本，不接收定位或几何。
- 自动流程不得复用可能陈旧的 React 快照状态；它重新读取完整当前快照并通过既有严格监控合同。断网时只有已验签、资产完整、仍在有效期且版本精确绑定的活动包可作为重算输入。
- 新路线必须具有不同指纹，并精确绑定景区、起点、原目的地、路网/运营版本、策略、优化和偏好；正式 version 变化还需通过确定性运营重算判断。成功才写 `REROUTED` 并恢复，失败继续停止并转现场标识/工作人员。
- 软件回归不能证明景区 GNSS、多路径遮挡、节点密度或反复偏航稳定性。正式启用仍需官方 GIS、真机矩阵、弱网/断网、现场封路改道与独立安全签字。

## DEC-0024 执行解释

- 路径几何中的坐标有两种语义：正式边端点是游客需要决策的拓扑节点，边内部坐标只描绘道路形状。运行时只在相邻 traversal 的边界比较出口/入口方位，避免弯道造型点产生虚假转向。
- 当前边的几何进度只用于计算该边的完成比例；剩余距离是当前边发布距离的剩余部分加后续边发布距离，ETA 同理使用各边时间。总体进度由逐边剩余距离反推，避免不同边量测比例造成显示漂移。
- 地图精度圈严格使用浏览器报告半径，最大只显示 2,000 米的有界 WGS84 多边形；异常、零值或越界定位不绘制。蓝/金/红只是定位状态辅助，必须与顶部文字状态、隐藏旧箭头和现场标识同时使用。
- 精度圈、当前点和质量颜色均只在浏览器内存及 MapLibre 数据源存在，不进入请求、CacheStorage、导航历史或日志。正式启用仍需正确边分段、逐边量测、真机多路径、强光/色觉/读屏和现场双向口令核验。

## DEC-0025 执行解释

- 每个可靠定位样本先投影到路线全部线段。首次遇到同等距离的重叠几何时选择最早进度；有历史时，只接受与上一进度相差不超过“本次实际移动 + 前后浏览器精度 + 15 米缓冲”的候选，避免回头线、交叉线或平行近线把游客瞬间送到路线远端。
- 若全局最近候选落在不连续远端分支并明显优于连续候选，单次只标为 `JUMP` 并停止方向；该样本通过传感器门后只更新设备内最新可靠定位，不推进旧路线进度。连续第三次才进入 `OFF_ROUTE/REROUTE_REQUIRED`，从最新可靠定位复用 DEC-0023 的正式节点、完整快照和不同指纹重算门。
- 反向行走只在仍可靠位于路线走廊内时判断：相对本次导航最远已达几何进度，扣除当前精度后反退至少 20 米，连续三个样本才显示 `WRONG_WAY` 与安全掉头。回到最远进度 8 米内清零；反向警告本身不请求新路线。
- 前一定位、当前/最远进度和证据计数都是运行时 tracker，只驻留浏览器内存，不进入导航 runtime 序列化、API、CacheStorage、导航历史或日志。15/20/8 米及三点门限是待现场标定的软件默认值，不能被表述为六祖镇正式安全参数。

## DEC-0026 执行解释

- 总体 `progressRatio` 由逐边发布距离计算，不能反向映射到几何切点；地图必须使用路线投影产生的精确线段索引和线段内比例，在线段插值点处生成已走与剩余两个 LineString。
- 未取得有效匹配时，显示整条蓝色待走路线且不生成灰色已走线；只有精确匹配终点才移除剩余蓝线。这样低精度、越界或损坏匹配不会制造游客已经走过的视觉事实。
- 索道/观光车 overlay 与总路线几何段数一致时从同一匹配点裁剪并移除已完成段；一旦 traversal 拓扑和总几何段数漂移，隐藏该进度敏感 overlay，不能把已乘服务重新显示为待乘。
- 暂停恢复保留最后确认的匹配、当前和最远进度，清除前一定位与所有连续证据计数。匹配段、比例和分段 GeoJSON 只存在 React/MapLibre 内存，不持久化或上传；灰/蓝颜色必须配合文字和读屏说明。

## DEC-0027 执行解释

- 相机跟随只在模式为 `FOLLOWING`、当前位置有界且导航质量为 `RELIABLE/ARRIVED` 时成立。低精度、等待、跳点、反向、偏航、暂停或路线停止均不能用旧点移动镜头。
- MapLibre 的真实拖动、缩放和旋转原始事件把状态切到 `BROWSING`；程序自己的 `easeTo/fitBounds` 不得误触发手动浏览。GPS 仍可更新位置与路线进度，但不会改变游客选择的视野模式。
- `OVERVIEW` 只使用 N16 生成的剩余路线坐标；剩余为空时只以正式终点为单点回退。游客显式点击“回到当前位置”且当前定位仍可靠时才返回 `FOLLOWING`。
- 相机模式只存在组件内存，不进入 API、导航历史、CacheStorage 或日志。自动化只证明状态合同和所列浏览器回放；正式启用仍需代表性真机、多点触控、系统缩放、旋转、前后台、低端 GPU、读屏和现场任务验收。

## DEC-0028 执行解释

## DEC-0029 执行解释

- 导航语音是可关闭的前台辅助通道，默认关闭且不跨页面持久化。全局静音有最高优先级；取消静音后也不会自动重新开启本次导航语音。

## DEC-0052 全站中文字体角色地图与开发预览

- 用户要求对全站中文字体做系统性视觉升级，而不是单一替换 `font-family`。决定建立 Hero、文化标题、历史/章节、游记人文、禅意标记和 UI 信息六类角色，并把角色映射落到首页、页头、导览、云游、AI、社区、地图、路线、弹窗、抽屉和移动端。
- 艺术字体只进入低频文化表达层：Hero 使用 Ma Shan Zheng，游记/故事使用 LXGW WenKai；Noto Serif SC 负责稳定的文化标题，Noto Sans SC 负责按钮、导航、表单、地图、数字、安全和密集信息。禁止全站刷体化和用艺术字承载操作语义。
- 新增 `docs/typography-audit.md`、`docs/typography-map.md`、`docs/font-license-status.md` 和开发环境 `/dev/typography` 预览页；预览页在生产环境返回 404，避免把内部比较工具暴露给游客。
- 商业候选字体保持“待授权”状态，不下载、不打包、不作为已获授权素材发布；开源字体依赖固定版本、本地构建、所需 CSS 子集和 `font-display: swap`，保持可替换和可回滚。

## DEC-0053 用户提供汉仪字体与方正云字库的安全接入

- 汉仪尚巍手书用于 Hero 首句，汉仪北魏写经用于短文化标题与景点名，汉仪曾翔禅趣体用于禅意标记；三者不进入按钮、地图标签、路线指令、表单、数字、错误或安全提示。

- 云字库失败或未配置时保持本地字体 fallback，且不阻塞页面；当前部署不宣称已取得方正云字库授权。来源、哈希、使用范围和发布边界登记在 `docs/font-license-status.md` 与 `THIRD_PARTY_MEDIA.md`。

## DEC-0054 用户提供方正字体文件后提升为本地文化主字体

# DEC-0051：全站动效强度分级与统一降级

- 日期：2026-08-17
- 状态：已批准并实施
- 决策：新增 `cinematic | expressive | utility` 三级内部动效强度；首页与云游可使用电影叙事级，游客任务页使用沉浸交互级，地图与管理页使用工具操作级。
