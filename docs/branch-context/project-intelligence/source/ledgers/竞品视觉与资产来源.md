## 使用说明

- 来源等级沿用《Discovery研究章程》：A 为政府、法规/标准、开放平台官方文档；B 为企业官方产品页、帮助文档、公告或案例；C 为游客/社交内容；D 为聚合或搜索线索。
- 本轮没有用 C/D 级来源证明事实，也没有下载外部图片、视频、音频、字体、图标、地图或 3D 文件。
- 企业产品页只能证明“企业在该页面声称或展示了该能力”；除官方操作文档明确行为外，不推断内部算法、准确率、覆盖范围或六祖镇适用性。
- 政府、景区、企业官网上的公开展示不等于开放版权。除页面或许可证明确授权外，媒体一律为“链接/研究参考”，不可直接商用、改编、再分发或公开部署。
- 动态产品页若未标注发布日期，写作“未标注（动态页）”；这类信息应在 Gate 1 和正式选型前复核。
