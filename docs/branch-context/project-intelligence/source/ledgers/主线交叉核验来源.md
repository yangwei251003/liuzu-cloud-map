## 交叉核验发现

- 官方资料支持“六祖镇—六祖故里旅游度假区—国恩寺等核心点”的层级关系，但尚不足以形成产品地图边界。
- 官方历史文化游径可作为内容策划线索，不能直接当作实时可导航路线；需核验道路、开放状态、距离、无障碍与安全。
- 国恩寺作为全国重点文物保护单位，文保约束会影响拍摄、定位、游戏化、AR/3D与现场引导设计，后续应取得管理方意见。
- 连续定位/轨迹与基于位置触发是核心价值，同时也是敏感个人信息高风险点；应默认最小化、就地处理优先、短期限和非必要不留完整轨迹。
- AI生成讲解、游记和媒体若可展示或分享，必须从一开始预留生成内容标识与来源溯源，而不是上线前补丁。
- 春节客流与短途自驾占比揭示了“高峰、近程、多人同行”的重要假设，但仍需淡季数据、现场访谈和全年度统计验证；不能把单一节假日样本当作完整用户画像。
- 在线景区信息已有专门行业标准；POI、开放状态、交通、票务、风险提示等不应只做内容文案，而要在产品设计阶段建立责任主体、采集时间、复核周期和失效机制。
- 2026版景区讲解标准在本次Discovery时尚未实施，项目应按“未来生效约束”预留核验项，并在正式上线前重新检查有效版本。
