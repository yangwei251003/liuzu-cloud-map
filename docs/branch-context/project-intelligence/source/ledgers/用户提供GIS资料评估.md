# 用户提供 GIS 资料评估

> 状态：`SOURCE_DISCOVERY_ONLY`  
> 核验日期：2026-08-15（Asia/Shanghai）  
> 边界：两篇文章是数据源导航，不是六祖镇官方空间数据，也不自动授予每个下游数据集的缓存、改编或再分发权。

## 1. 博客园 GIS 数据合集

- 原文：[GIS数据下载合集：遥感、土壤、气象、行政区数据……](https://www.cnblogs.com/fkxxgis/p/17044278.html)
- 页面声明的最近更新时间：2022-03-20。
- 主要价值：按遥感、气象、土地覆盖、高程、水体、行政区、路网、建筑、POI、GPS 等类别整理数据入口，适合作为**发现清单**。
- 与本项目直接相关的入口：OSM 路网/行政区、建筑轮廓、POI、ASTER GDEM/AW3D30 高程等。
- 采用判断：
  - OSM 已用于当前候选道路、建筑、水系和候选点演示，并保留 ODbL 来源/时间/候选标识；
  - 30 m DEM 可在后续做坡度初筛，但分辨率不足以替代景区台阶、坡道、无障碍和真实路面现场核验；
  - 全国/全球行政区、土地覆盖、气候与遥感影像不是首版“入口—内部路网—设施—导航”闭环的关键数据，暂不为下载而下载；
  - 文中第三方入口必须逐个回到数据提供方核对许可、版本与下载方式，不能直接镜像文章或图片。

## 2. 知乎 9 个免费 GIS 数据网站

- 原文：[【收藏】9个免费的GIS数据下载网站](https://zhuanlan.zhihu.com/p/141776702)
- 页面显示编辑时间：2020-05-18。
- 文章列出的入口包括：地理空间数据云、国家卫星气象中心、中国科学院数据云、国家地球系统科学数据共享服务平台、资源环境数据云平台、Natural Earth、OpenStreetMap、USGS、FAO GeoNetwork。
- 采用判断：
  - 对六祖镇步行导览，OpenStreetMap 是该清单中粒度最接近当前需要的开放候选底图来源；当前项目已经下载并校验相应 OSM 派生 GeoJSON；
  - Natural Earth 面向全球/国家级制图，粒度不适合景区内部步行导航；
  - Landsat、MODIS、风云、USGS/FAO 等主要面向遥感、环境或宏观专题，不包含可直接发布的景区入口、内部道路、厕所、游客中心或动态封闭；
  - “免费可下载”不等于“适合导航”“可公开再分发”或“已现场核验”。

## 3. 对当前资产库的结论

| 数据类别 | 当前处理 | 原因 |
|---|---|---|
| 道路、建筑、水系、候选设施 | 已保留 OSM 本地快照与来源清单 | 可形成离线演示底座，但继续标 `UNVERIFIED` |
| 景区正式边界、入口、内部路网 | 不从上述文章推断 | 必须由管理方/现场证据发布 |
| 高程/坡度 | 后续可下载 DEM 做研究初筛 | 不能替代台阶、坡道、路面和无障碍现场测量 |
| 遥感/气象/土地覆盖 | 暂不下载 | 首版无直接消费场景，避免堆积无用途、许可不明的大文件 |
| POI/设施 | 仅作为候选发现 | 名称、坐标、类型、开放状态、无障碍与责任来源仍须复核 |

以上评估已落实“只下载产品会实际消费的数据”。当前未复制两篇文章的图片或全文，也未把文章作者的描述升级为官方事实。
