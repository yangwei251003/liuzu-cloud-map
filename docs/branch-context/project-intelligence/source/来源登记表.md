## 可信等级与统一限制

- A1：法律法规、标准原文、法定名录、正式政府文件；可支持其明确覆盖的规范或法定事实。
- A2：政府/主管部门原创公告、介绍和统计发布；可支持“该机构在该时点的官方口径”，但宣传、规划、初步统计和动态运营仍须按用途复核。
- B：政府门户转载媒体、领导访谈、企业官方产品/案例、权威机构或学术资料；用于相应时点的发布方主张、产品能力或交叉证据，不等同于独立审计、实时状态或法定边界。
- C：旅游平台、商户页面和公开 UGC；仅用于发现行为、痛点和体验信号，不能单独证明历史、坐标、开放、价格或设施事实。
- D：博客、论坛、聚合、转载与搜索摘要；只用于发现来源，不能作为最终证据。

各分账本沿用简写 `A/B/C/D` 时，以本节和该账本“限制”栏共同解释；同一页面若在多个账本出现，等级差异不得改变正文的实际使用限制。
