## Style-transfer 提示词

将参考图中的复古国风地图视觉提炼成可叠加在真实高德地图上的装饰层：玄青底、鎏金细线、传统云纹、山峦与建筑边缘纹样；严禁生成或改写道路、地名、国界、坐标、POI 和任何文字；中央地图阅读区保持干净，装饰集中在四周。

## Background-extraction 提示词

移除所有暗色或棋盘格背景，输出真实透明 Alpha；仅保留鎏金边框、深青云纹与四周装饰；中央至少 70% 完全透明；不得包含地图、道路、地名、UI 控件或文字。

## 使用边界

该文件只作为高德事实底图的视觉边缘装饰，不参与地理表达，不对应真实地形，不改变官方国界、道路、地点、坐标或导航结果。
