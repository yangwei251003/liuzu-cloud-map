## 目录说明

- `prompts/`：历史对话中确定的角色、调研、研发、权限和长期战略提示词
- `source/`：本地原始资料、需求理解与来源登记
- `discovery/`：七份 Discovery 研究报告
- `assets/`：图片、视频、音频、地图、3D、UI参考等资产及许可台账
- `decisions/`：需要长期保留的产品与技术决策
- `risks/`：事实、数据、版权、成本、技术与范围风险
- `handoffs/`：阶段审核包和后续阶段移交说明
- `readiness/`：Gate 2 后六项开工准备度的计划、证据台账和授权请求

`product-design/` 与 `technical-design/` 是第二阶段批准蓝图；`source-code/` 已按用户授权解锁并形成可重复验证的演示版。历史 Gate 2/准备度文档保留当时快照，不覆盖当前状态源与最终验收报告。
