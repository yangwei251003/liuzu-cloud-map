# 评委演示脚本 (Judge Demo Script)

## 5 分钟黄金演示脚本

1. **[0:00 - 0:30] 平台背景与三端架构**
   - 访问 `/judge` 演示中枢。
   - “云游地图将分散的文旅资源变成可提交、可审核、可落图、可发现、可导航的数字资产。”
2. **[0:30 - 1:45] 商户端 (云游伙伴中心) 提交活动**
   - 点击“商户端”进入 `/partner/activities/new`。
   - 填写“禅茶一味·秋季制茶体验”，在地图上点选国恩寺附近茶园。
   - 提交审核。
3. **[1:45 - 2:45] 管理端 (云游 Studio) 审核与落图**
   - 切换到 Studio 端 `/studio/reviews`。
   - 审核刚刚提交的茶艺体验，在地图编辑器中微调经纬度。
   - 批准发布，并勾选“首页推荐”。
4. **[2:45 - 4:00] 游客端 (云游地图) 发现与导航**
   - 切换到游客端 `/map` 或 `/explore`。
   - 看到刚刚发布的茶艺活动已在地图上高亮展现。
   - 点击查看详情、点击收藏，点击“出发导航”调起真实高德路线规划。
5. **[4:00 - 4:45] 数据回流与闭环验证**
   - 回到 Partner 仪表盘，展示“查看次数 +1，导航启动 +1”。
6. **[4:45 - 5:00] 一键重置与结语**
   - 在 `/judge` 演示一键恢复初始数据，展现系统的高健壮性。
