# 游客端 PRD：云游地图 (Visitor Portal)

## 1. 目标与定位
为到访新兴县六祖镇的游客提供以地图为核心的文旅发现、活动体验、景点详情与路线导航服务。

## 2. 页面与功能清单 (P0)
1. **地图主界面 (`/map` & `/`)**
   - 展现高德地图底图，标注景点（文化、山水、休闲）与已发布商户体验活动。
   - 分类过滤：全部、文化古刹、在地体验、特色餐饮、休闲汤泉。
   - 地图标记与底部卡片联动：点击 Pin 弹出微缩预览卡片（名称、类别、简评、封面图、“去这里”按钮）。
2. **发现与列表页 (`/explore`)**
   - 精选地点卡片瀑布流、最新商户文旅活动推荐。
3. **地点/活动详情卡片 (`/place/:id`, `/activity/:id`)**
   - 标题、商户所属、开放时间/活动时间、价格说明、地址与联系方式、地图定位。
   - 交互操作：“一键收藏”、“发起导航”（联动高德路线规划）。
4. **轻行程与收藏 (`/trip` & `/journey`)**
   - 本地持久化收藏列表，无需强制登录即可记录，随时可删除或定位回地图。
5. **高德地图真实导航联动**
   - 调起现有高德路线规划，展示步行/驾车距离与预计耗时。
