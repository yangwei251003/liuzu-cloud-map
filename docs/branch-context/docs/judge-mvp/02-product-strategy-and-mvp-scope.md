# 云游地图三端 MVP：产品定位、战略与 MVP 范围

## 1. 产品核心定位

**云游地图**将分散的县域文旅资源（景区、民宿、合作社、农家乐、非遗工坊、研学基地、节庆活动等）转化为**可提交、可审核、可落图、可发现、可导航、可运营**的数字化资产。

### 核心定位三要素
1. **游客视角**：沉浸、可信的在地数字导览与探索伙伴。
2. **商户/合作社视角**：零技术门槛入驻，快速在文旅地图上展现自身资源与体验。
3. **平台与管理视角**：内容治理、点位落图校准、推荐编排与真实数据运营。

## 2. 评委演示叙事与黄金路径

### 核心叙事
> “县域文旅数字化不是简单的网页列表，而是让乡村与景区的经营主体自己能把好内容放上地图，运营方能快速把关落图，游客能在地图上直观发现并发起导航的完整数字闭环。”

### 黄金演示路径（Golden Path）
```text
[云游伙伴中心 (Partner)]
  1. 商户登录演示账号（六祖禅茶合作社）
  2. 填写并提交“禅茶一味·秋季制茶与品茗体验”活动
  3. 地图选点定位、填写时间/价格/人数/图片
  4. 确认无误后提交审核
          ↓
[云游 Studio (管理与创作端)]
  5. 运营人员在“待审核”队列中看到新提交活动
  6. 检查资料、在地图编辑器中微调经纬度与标记
  7. 填写审核意见，点击“通过并发布”并设为“首页推荐”
          ↓
[云游地图 (游客端)]
  8. 游客进入地图首页，即时在推荐卡片或地图上看到该新活动
  9. 查看活动图文详情、价格、联系方式
 10. 点击“收藏”，一键进入“路线规划/发起导航”
          ↓
[数据回流闭环]
 11. 产生 查看/收藏/导航 事件
 12. 回到 Partner 或 Studio 端查看指标即时更新
```

## 3. 三端 MVP 范围界定（P0 vs 明确不做）

| 维度 | P0 必需实现（本轮交付） | 明确不做（避免过度工程） |
| :--- | :--- | :--- |
| **游客端** | 地图发现、分类图层筛选、活动/地点详情、无缝收藏持久化、高德地图路线导航 | 陌生人社交聊天、大型UGC审核流、支付与订单、多语言 |
| **Studio 端** | 待审核工作台、一键通过/退回/发布、地图落图微调、推荐位编排、审计日志 | 可视化整站搭建器、低代码引擎、复杂多级租户RBAC、大规模GIS重算 |
| **Partner 端** | 价值介绍页、分步提交向导（地点/活动）、地图打点、审核状态时间线、基础数据看盘 | 在线电子签约、支付结算、优惠券核销、分销裂变 |
| **跨端支撑** | 统一领域模型、Demo Adapter（IndexedDB持久化）、演示身份一键切换、一键重置数据 | 真实第三方短信验证码、外部公网支付接入 |
