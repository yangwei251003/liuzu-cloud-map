# 商户资源入驻端 PRD：云游伙伴中心 (Partner Portal)

## 1. 目标与定位
为景区商户、村集体、农业合作社、民宿主、非遗工坊提供极简的资源入驻与活动发布工具，透明化审核流程。

## 2. 页面与功能清单 (P0)
1. **入驻说明与价值主页 (`/partner`)**
   - 入驻价值介绍（零费用、入驻即落图、游客直达）、入驻主体类型与所需资料指引。
   - 登录/快捷进入演示工作台。
2. **商户工作台 (`/partner/workbench`)**
   - 我的主体资料与认证状态。
   - 我的资源列表（地点/门店）与我的活动列表。
   - 快捷发布入口。
3. **分步发布向导 (`/partner/resources/new`, `/partner/activities/new`)**
   - 第1步：基础信息（名称、类别、简介、联系方式）
   - 第2步：地理位置（地图选点打点、输入详细地址）
   - 第3步：经营/体验信息（时间、费用/免费说明、人数限制、预约要求）
   - 第4步：照片上传与预览
   - 第5步：提交审核（生成 PENDING_REVIEW 状态）
4. **审核进度与修改追踪 (`/partner/submissions`)**
   - 提交历史时间线，清晰显示“审核中”、“已通过上线”、“需修改”。
   - 收到退回修改意见时，支持原地修改并重新提交。
5. **基础经营表现看盘 (`/partner/insights`)**
   - 真实统计当前商户资源在游客端的查看量、收藏量、导航启动量。
