# UI 设计系统与线框规范

## 1. 颜色与 Token 体系
- **松绿 (Pine Green)**: 主操作、品牌色 (`#1b3a32`)
- **月白 (Moon White)**: 底色背景 (`#f5f7f3`)
- **路线金 (Route Gold)**: 导航轨迹高亮、重点推荐 (`#d49e35`)
- **荔红 (Lychee Red)**: 提醒标签、在地特色印章 (`#c43c35`)

## 2. 三端布局差异
- **游客端**：移动优先，全屏高德地图底盘 + 悬浮胶囊搜索 + 底部上拉抽屉卡片。
- **Studio 端**：桌面优先，深松绿侧边栏导航 + 白色内容卡片区 + 地图分屏编辑面板。
- **Partner 端**：友好温暖，居中卡片表单向导 + 步骤进度指示条 + 提交状态时间轴。
