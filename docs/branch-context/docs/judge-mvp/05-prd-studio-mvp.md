# 管理与创作端 PRD：云游 Studio (Studio Portal)

## 1. 目标与定位
为文旅运营人员、景区管理方提供统一工作台，实现商户入驻审核、内容质量管控、地图点位校准落图与推荐位编排。

## 2. 页面与功能清单 (P0)
1. **工作台总览 (`/studio`)**
   - 核心指标看板：待审核任务数、已发布资源总数、活跃活动数、游客浏览与导航总次数。
   - 待办列表与快捷处理入口。
2. **审核中心 (`/studio/reviews`)**
   - 队列分类：待审核 (Pending)、已通过 (Approved)、已退回 (Changes Requested)、已拒绝 (Rejected)。
   - 审核详情视图：左侧查看商户提交图文/营业时间/价格，右侧游客端效果即时预览。
   - 审核操作：一键通过发布、退回需修改（必填原因）、拒绝。
3. **资源与活动管理 (`/studio/resources`, `/studio/activities`)**
   - 查看全平台地点与活动，支持在线编辑、上下架状态切换。
4. **地图内容编辑器 (`/studio/map-editor`)**
   - 基于地图视图交互选择点位，拖拽或点击修正经纬度坐标，更新地图分类图标。
5. **推荐位编排 (`/studio/featured`)**
   - 将优质地点或当季活动置顶/设为“首页推荐”，实时影响游客端展示。
6. **审计历史与日志**
   - 记录每次审核、发布、修改的操作人与时间戳。
