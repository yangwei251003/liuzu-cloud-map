# 信息架构与线框设计 (05-information-architecture-and-wireframe.md)

## 1. 首页“地图优先”信息架构 (IA)

```mermaid
graph TD
    Root[首页 /] --> Nav[精简主导航栏 (高度 68-72px)]
    Nav --> NavItems[Logo | 首页 | 行程 | 地图 | 社区 | 我的 | 登录/注册]
    
    Root --> MapHero[地图主舞台 Hero (min-height: calc(100svh - 72px))]
    MapHero --> TopBar[顶部悬浮搜索与五类能力快捷胶囊]
    TopBar --> Action1[🗺️ 查看点位]
    TopBar --> Action2[🧭 路线导航]
    TopBar --> Action3[📅 行程规划]
    TopBar --> Action4[🎨 图层/皮肤]
    TopBar --> Action5[💬 地点社区]
    
    MapHero --> LayerControl[右上角：紧凑图层/皮肤选择器]
    MapHero --> MapNative[右下角：地图缩放 / 定位 / 复位]
    MapHero --> SelectedCard[左下/底部：选中点位详情与行动卡]
    SelectedCard --> BtnStory[听故事]
    SelectedCard --> BtnNav[导航去这里]
    SelectedCard --> BtnPlan[加入行程]
    SelectedCard --> BtnSocial[地点打卡讨论]
    
    Root --> BelowFold[地图后续内容区 (自然流动)]
    BelowFold --> Section1[五大地图核心能力特色解析]
    BelowFold --> Section2[推荐禅意路线与逐站详情]
    BelowFold --> Section3[实景影像与文化宣传专区]
    BelowFold --> Section4[社区游客精选动态]
    BelowFold --> Footer[页脚与审图/版权说明]
```
