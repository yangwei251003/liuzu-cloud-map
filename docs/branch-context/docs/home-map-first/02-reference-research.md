# 优秀案例调研与启发 (02-reference-research.md)

## 1. 调研目标
提炼业内“地图即首屏（Map-First）”类优秀产品的空间布局、信息层级、浮层控件规范、五类能力贯通方式以及登录页设计，指导“云游地图”的精细化重构。

---

## 2. 案例分析与提炼

### 案例 1：Google Maps (Web 桌面端 & 移动端)
- **空间占比**：地图占据 100% 全视口背景。
- **浮层架构**：左上方浮动搜索框 + 紧凑分类 Chip（餐馆、景点、加油站等）；左侧抽屉承载详情与路线规划；右下角聚合定位、缩放、图层切换。
- **可借鉴点**：
  - 地图完全不被分割，浮层使用毛玻璃/白底阴影悬浮于地图上方（占屏幕 < 30%）；
  - 单击地图空白处自动收起面板，保证最大化探索空间。
- **不可照搬点**：六祖云游为文旅垂直产品，需承载文化故事与旅程规划，不能仅有枯燥的搜索框。
- **本项目启发**：首屏采用全屏/主视口沉浸地图，主搜索栏与五类核心快捷入口以悬浮胶囊形式置于顶部，选中点位时滑出左侧或底部卡片。

### 案例 2：高德地图 (Amap Web & App)
- **空间占比**：主屏地图优先，提供多种地图图层切换。
- **控件组织**：图层控制收纳为右上方悬浮图层按钮，点击展开图层切换弹层；右下角为定位与缩放。
- **可借鉴点**：
  - “地图风格”不占用页面固定行高，而是作为地图内部右上/左下的悬浮轻量菜单；
  - 道路导航与驾车/步行切换直观。
- **不可照搬点**：商业广告与弹窗较多。
- **本项目启发**：将原本横跨一整行的“标准/禅意/青山/复古/3D”地图风格压缩为地图右上角的“紧凑图层菜单”。

### 案例 3：Wanderlog (行程规划与旅游地图)
- **空间占比**：左侧 40% 行程路线节点，右侧 60% 动态地图，点选联动。
- **可借鉴点**：
  - 点击左侧景点，地图平滑飞移到对应 Marker，并弹出“加入行程”和“导航”按钮；
  - 路线按天或按主题串联，地图上清晰绘制路径折线。
- **本项目启发**：首页选中点位后，卡片上直接提供“加入行程”与“以此为起点/终点导航”的快捷 Action。

### 案例 4：AllTrails & Komoot (户外探索与社区轨迹)
- **空间占比**：首屏大地图展示探索热点，卡片横向轮播叠加在底部。
- **可借鉴点**：
  - 点位不仅显示基础信息，还显示“游客真实打卡数”、“社区最新照片”；
  - 点击“社区”直接带入当前点位 ID 筛选出同好打卡。
- **本项目启发**：点位卡片内提供“查看该地点社区”入口，携带 `spotId` 跳转到社区并自动过滤，实现地图到社交的自然贯通。

### 案例 5：现代品牌化登录/注册页 (如 Airbnb / Linear)
- **布局**：桌面端优雅双栏——左侧展示高质量实景/意境地图插画与品牌核心价值承诺（“无需手机号，纯净无扰探索”），右侧为精致高对比表单卡片；移动端自适应单栏。
- **交互**：
  - 支持 `?redirect=` 参数，登录成功后精准恢复用户刚才操作的上下文（如正在规划的行程）；
  - 提供醒目的“暂不登录，返回地图探索”按钮。
- **本项目启发**：重做 `/account` 视觉，左侧融入六祖云游实景与“地图探索”理念，右侧优化表单状态与错误提示，并加入返回原路线上下文的重定向。

## 3. 对本项目的重构指引总结

1. **首屏面积**：桌面端地图可视高度达到 `calc(100vh - 72px)`，无大幅轮播或冗长文字阻挡，首屏地图面积占比 > 70%。
2. **浮层控制**：浮层总面积 ≤ 30%，使用高可读性半透明毛玻璃与圆角（`rounded-2xl`），保证地图背景穿透感。
3. **五类入口贯通**：
   - 🗺️ **查看**：全景浏览 + 点位聚合 + 分类筛选；
   - 🧭 **导航**：点位直达高德步行/驾车导航引擎；
   - 🎨 **交互**：紧凑图层菜单、定位、复位、缩放；
   - 💬 **社交**：点位卡联动社区实景打卡与讨论；
   - 📅 **规划**：一键将选中点位加入行前路线草稿或拉起智能规划。
