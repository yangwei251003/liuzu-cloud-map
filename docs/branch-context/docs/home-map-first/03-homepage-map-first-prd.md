# 首页“地图优先”产品需求文档 (03-homepage-map-first-prd.md)

## 1. 产品背景与目标
- **核心诉求**：用户进入网站后，第一眼即认知“这是一个以真实交互地图为核心的旅游服务平台”。
- **目标指标**：
  1. 首屏 1440×900 / 1920×1080 视口中，真实交互地图无需滚动即可完整操作，视觉覆盖率 ≥ 70%；
  2. 首屏 1 次点击即可直接进入五大核心能力（查看、导航、交互、社交、规划）；
  3. 原宣传轮播、文化深度解读、景点详细列表等内容退至地图之后，形成“先在地图上探索，后滑看深度详情”的连贯旅程。

---

## 2. 功能范围与用户故事

### 2.1 核心用户故事 (User Stories)

| 编号 | 核心能力 | 用户故事 | 验收标准 |
| :--- | :--- | :--- | :--- |
| **US-01** | **地图查看** | 游客打开首页，首屏直接看到新兴县核心景区（国恩寺、六祖故居、藏佛坑等）的高德真实地图分布，可拖拽、缩放、点击点位。 | 首屏主舞台即为真实地图，加载骨架友好，支持手势与鼠标操作。 |
| **US-02** | **地图导航** | 游客在地图上选中“国恩寺”，可点击“导航到这里”，立即拉起站内高德真实路线导航（步行/驾车）。 | 联动 `AmapEmbeddedNavigator` 或 `/guide` 导航流程，提供清晰起点/终点与定位降级。 |
| **US-03** | **地图交互** | 游客希望切换“禅意皮肤”、“青山绿水”或“标准高德”，点击右上角紧凑图层菜单即可即时切换，不占页面高度。 | 图层菜单支持收起/展开，支持标准、禅意、青山、复古、3D 等模式，保留高德版权审图号。 |
| **US-04** | **地图社交** | 游客在点位详情卡中点击“查看地点社区”，可带入该地点参数进入社区，浏览同地点游客实景打卡与讨论。 | 链接携带 `?spot=xxx` 或跳转至 `/community/[id]`，无死链接。 |
| **US-05** | **地图规划** | 游客选中点位后点击“加入行程”或“开始规划”，可调起智能路线规划器，将该地点作为途经点加入草稿。 | 路线生成器与本地 `journey-store` 联动，支持生成后在地图上实时绘制轨迹。 |

---

## 3. 非目标 (Non-Goals)
1. 不重写导航核心算法（复用现有高德路径规划引擎）；
2. 不新建完整社交后端（复用现有社区组件与地点筛选）；
3. 不删除地图供应商版权与审图号标识；
4. 不修改全站路由定义；
5. 不引入虚假的静态地图截图伪装。

---

## 4. 边界与降级策略
1. **高德地图离线或无网络**：自动降级为 MapLibre 本地矢量瓦片，并在左上角状态栏给出合规友好说明；
2. **浏览器定位权限被拒绝**：默认以景区中心（六祖故里核心区）为视野中心，并在尝试定位时弹出清晰权限指引；
3. **小屏幕/移动端适配**：移动端 (390×844) 首屏同样以地图为主，详情面板收纳为底部抽屉，避免遮挡地图。
