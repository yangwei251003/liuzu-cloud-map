# 验收标准清单 (08-acceptance-checklist.md)

## 1. 首页“地图优先”验收项

- [ ] **AC-01 真实地图首屏**：在 1440×900 视口下无需滚动，地图直接呈现于导航栏下方，覆盖 ≥ 70% 可视面积。
- [ ] **AC-02 无多余阻挡**：导航栏与地图之间无大幅轮播图、长宣传文案或大面积留白。
- [ ] **AC-03 紧凑图层控制**：地图皮肤（标准、禅意、青山、复古、3D）以紧凑悬浮控件形式内置于地图内，不再独占整行。
- [ ] **AC-04 地图查看与交互**：地图支持拖拽、滚轮缩放、双击缩放、重置视野，点位点击有高亮动效。
- [ ] **AC-05 地图导航能力**：选中点位后点击“导航去这里”，可无缝拉起站内高德真实路径导航。
- [ ] **AC-06 地图规划能力**：可从选中点位一键加入行程或拉起智能路线规划器。
- [ ] **AC-07 地图社交能力**：点击点位卡“地点社区”，携带地点 ID 准确进入社区相关动态。
- [ ] **AC-08 地图之后的内容**：原轮播宣传、深度文化说明、推荐路线自然排列在地图下方，向下滚动顺畅。
- [ ] **AC-09 版权合规**：高德地图审图号与版权标识完整保留且不被遮挡。

---

## 2. 登录/注册页验收项

- [ ] **AC-10 品牌化双栏布局**：桌面端左侧呈现云游地图品牌与隐私优势，右侧为精致表单；移动端自然折叠为单栏。
- [ ] **AC-11 鉴权接口严格兼容**：完整沿用 `/api/v1/auth/login`、`register`、`logout`、`me`，未更改字段或后端逻辑。
- [ ] **AC-12 密码显隐与格式校验**：支持密码明密文切换，具备 3~32 位 Handle 与 ≥12 位口令即时校验。
- [ ] **AC-13 回跳机制 (Redirect)**：支持 `?redirect=` 参数，登录成功后正确回跳至来源页面。
- [ ] **AC-14 返回通道**：提供清晰的“返回地图探索”按钮，随时可返回首页。
- [ ] **AC-15 无伪造登录方式**：不展示未接入的第三方登录按钮。

---

## 3. 工程与质量验收项

- [ ] **AC-16 原仓库零污染**：原工作区 `[local-project-path]` 保持原分支与原状态未被修改。
- [ ] **AC-17 自动化测试 100% 通过**：全量单元测试与类型检查无任何错误。
- [ ] **AC-18 多视口响应式**：390px、768px、1440px、1920px 均无水平溢出或组件遮挡。
- [ ] **AC-19 浏览器控制台无报错**：无未捕获异常或内存泄漏警告。
