## 核心业务闭环：黄金演示路径 (Golden Path)

评委可按照以下 **5 步黄金路径** 完整检验三端端到端协作：

```
[商户端] 伙伴中心申报采茶/陶艺新活动
       ↓ (生成待办、录入草稿快照)
[Studio端] 审核中心接收申报 → 双栏比对 → 拖拽/微调高德经纬度落图 → 设为精选推荐 → 审核通过发布
       ↓ (跨端响应式事件广播、数据持久化)
[游客端] 文旅发现页 & 高德互动地图 即时出现新体验 → 查看图文详情 → 游客收藏 → 发起高德导航
       ↓ (行为漏斗数据实时回流)
[商户端] 伙伴中心转化看板 实时看到曝光量、收藏量、导航出发量的增长曲线
```

### 步骤详情

1. **第一步：商户申报体验活动**
   - 切换身份为 **商户 (六祖禅茶合作社)**
   - 访问 `/partner/activities/new`
   - 填写体验活动（如“金秋禅茶雅集·制茶品茗体验”，单价 ¥168，每日两场）
   - 点击“提交审核” → 状态流转为 `待运营审核 (pending_review)`

2. **第二步：Studio 运营审核与落图校准**
   - 切换身份为 **Studio 管理端**
   - 访问 `/studio/reviews`
   - 在左侧待办列表选择刚才商户提交的活动
   - 在右侧审核卡片中：
     - 点击预设快速定位或微调经纬度（如 `22.5890, 112.2320`）
     - 勾选“设为首页与地图精选推荐”
     - 填写运营寄语，点击“审核通过并正式发布”
   - 状态流转为 `已正式发布 (published)`

3. **第三步：游客端即时发现与互动**
   - 切换身份为 **游客**
   - 访问 `/explore`（文旅发现页）或 `/map`（高德地图页）
   - 刚发布的活动已即时出现在“当季精选在地体验”和地图顶部高亮卡片中
   - 点击进入 `/activity/[id]` 详情页
   - 点击“收藏活动”与“调起高德地图出发导航”

4. **第四步：游客轻行程与收藏清单**
   - 访问 `/trip`，刚才收藏的活动与地点已安全保存在个人轻行程中，支持一键导航。

5. **第五步：商户端数据看盘回流**
   - 切换回 **商户**，访问 `/partner/insights`
   - 查看经营看板：浏览量 (Views)、收藏量 (Favorites)、导航出发量 (Navigations) 已实时统计并呈现转化漏斗与事件时间线。

## 三端页面完整架构清单

### 1. 云游伙伴中心 (Partner Portal) · 绿色大地生态风
- `/partner`：伙伴入驻首页（入驻权益、合作社赋能、快速通道）
- `/partner/workbench`：商户核心工作台（经营概览、待办事项、已发布活动列表）
- `/partner/activities/new`：特色文旅活动申报向导（4步表单、高德坐标拾取、定价、图片上传）
- `/partner/resources/new`：实体空间地点申报向导（基地、茶园、客栈点位申报）
- `/partner/submissions`：申报历史时间线（全生命周期状态追踪、退回重新编辑提审）
- `/partner/insights`：经营数据转化看盘（曝光/收藏/导航漏斗、实时事件流）

### 2. 云游 Studio (Admin & Creator Portal) · 深色专业控台风
- `/studio`：Studio 运营总览（待审队列、上架资源、全域互动指标看板）
- `/studio/reviews`：双栏内容审核台（图文核验、高德落图校准、批量一键发布/驳回）
- `/studio/resources`：全域实体地点与资源台账（上下架开关、分类筛选、属性微调）
- `/studio/activities`：特色文旅体验活动台账（主办方关联、排期价格管理）
- `/studio/map-editor`：地图点位落图校准台（坐标微调、GCJ-02 预设对齐）
- `/studio/featured`：首页与地图推荐位编排（精选气泡高亮编排）

### 3. 云游地图游客端 (Visitor Portal) · 文旅游客与地图发现
- `/explore`：文旅发现流（分类标签筛选、当季体验瀑布流、核心胜境卡片）
- `/place/[id]`：地点胜境深度详情（画廊、开放时间、门票、设施标签、收藏、高德导航）
- `/activity/[id]`：文旅体验深度详情（排期、预约方式、主办商户、费用、收藏、导航）
- `/trip`：游客收藏与轻行程（离线持久化、一键导航路线）
- `/map`：高德地图全景联动（实时展示最新发布的商户体验与点位）
