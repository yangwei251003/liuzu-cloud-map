# 现场与真机测试清单

**当前没有任何现场项可标记 PASS。** 本清单是后续证据模板；仓库源码测试、候选地图或旧演示记录不能替代现场记录。每次执行均需记录最终提交、发布快照 ID、路网/运营版本、设备/浏览器、网络、天气、测试人、原始证据位置、管理方签字和独立 GIS/安全审核签字。

## 路线与定位

- [ ] 每个已发布入口/出口、路口、单向边正反向复走；入口、边和现场观察应可回溯至同一发布快照。
- [ ] 偏移、跳点、低精度、树荫/建筑遮挡、前台/后台/锁屏边界；确认系统暂停而非继续错误引导。
- [ ] 交叉、重叠、平行、回头和相邻远端路段的正反向地图匹配；确认进度连续、不跳终点，真实折返出现掉头提示且回到最远进度附近后稳定恢复。
- [ ] 灰色已走线、蓝色剩余线及剩余索道/观光车虚线逐段与现场位置核对；覆盖起点、边界、换乘、终点、低精度冻结、暂停恢复和无效匹配全量待走回退。
- [ ] 导航地图视野：可靠定位自动跟随；拖动/缩放/旋转进入手动浏览；总览仅包含剩余路线且连续 GPS 不抢回；显式回中恢复跟随；低精度、停止、前后台及设备旋转不产生意外镜头移动。
- [ ] 页面生命周期：Android/iPhone 逐一执行切后台、锁屏、返回、BFCache、系统回收、权限撤回和 1/5/30 分钟后台；确认监听停止、旧指令隐藏、回前台先复核、没有自动恢复，显式确认后才接受新鲜定位。
- [ ] 前台关键语音：默认关闭、显式开启和立即关闭；逐段核对路线修订、正式路段、转向/交通语义、距离分档和去重；低精度、跳点、偏航、反向、运营版本变化、暂停、后台、退出、到达与全局静音均取消或替换旧播报，不在恢复前读取后台前定位。
- [ ] 封路发布、状态过期、网络/页面恢复和无安全替代路线；确认旧指令停止并转人工求助。
- [ ] 台阶、坡度、宽度、无障碍绕行和风险区；由独立审核人核验实际可达性。

## 体验、内容与无障碍

- [ ] 弱网、断网、离线数据时间、地图/AI/语音的安全降级；离线包不得包含无合同许可的地图瓦片。
- [ ] 讲解驻留、快速穿越、冷却、暂停/继续、静音区、音频失败后的审核文字与来源回退。
- [ ] 110、120、**已核验**景区电话、出口/服务点/医务室和路线纠错；未核验渠道必须显示不可用，不得伪造号码。
- [ ] 系统字号、200%/400% 缩放、无横向溢出、全键盘、读屏语义、非颜色状态、视觉+语音导航和触控面积。
- [ ] Android/iPhone 的 Safari/Chrome/微信内置浏览器分别覆盖系统静音、音量变化、中文声音、耳机/蓝牙、来电/媒体抢占、噪声与静音区；语音失败时审核文字、地图、方向和现场标识仍可独立完成任务。

## 安全、隐私与运营

- [ ] 分享 fragment 在解析后清除；token 不进入请求 URL、Referer、缓存、日志或截图。
- [ ] 导出、删除、会话撤销、撤回同意和本机清理；在真库/真身份条件下重复验证。
- [ ] 运营封路/通知的预授权、强制失效、事后复核、回滚和审计；确认不依赖前端重新部署。
- [ ] 应急演练：定位不可用、路网/运营状态过期、无安全路线、人工求助和责任人响应。

`../src/lib/route-operation-monitor.ts`、`../tests/route-operation-monitor.test.mjs` 等仅提供测试前提；直到本清单逐项有签字和版本化证据，路线与安全相关放行规则仍为 `UNVERIFIED`。
