# 项目家族与来源

本仓库 main 是 Next.js 云游地图主版，three-role-mvp 是保留独立产品增量的三端开发线。另一个仓库 liuzu-cloud-tour 是 Vite/React 网页，不能用它的功能或测试代替本仓库。

主版原提交 1938c06cd7493f8308aa3244b690f9eeb0b5d935，三端原提交 10b80795eb6dfc891b2e5c22476aefd3a2ac8660。比较的是本机实际工作文件，包含未提交增量：主版 627 个受跟踪文件及 25 个新增源文件；三端 web 有 747 个受跟踪文件。两者共有 627 个原跟踪路径，其中 605 个工作文件字节一致、22 个不同；主版 25 个新增源文件在三端均有对应，24 个一致。三端额外 95 个路径中，51 个是 database/database、docs/docs 的重复副本，44 个是独立增量。未证明共享 Git 祖先，不把文件相似度当作提交历史。

两条开发线分别保留当前源码、测试、数据库迁移、公开资料与平台壳；三端额外保留商户提交/运营审核/演示身份等实现。没有把两套工作目录覆盖到一起。外部设计/验收文档仅供理解原型，不能据此宣称生产服务已经上线。

涉及未确认再分发权的素材、商业字体、私人环境文件以及原始 OSM 下载未放入仓库；来源与哈希索引见 docs/provenance。公开 OSM 派生数据仍遵守 ODbL，图像各自许可见 THIRD_PARTY_NOTICES.md。
