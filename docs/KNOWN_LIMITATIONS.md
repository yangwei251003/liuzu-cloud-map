# 已知限制

1. 当前仓库最多形成受控公开测试候选，不能声明为景区官方安全导航产品或生产服务。
2. 官方边界、入口、路网、设施、风险、开放规则、联系方式和文化内容尚未作为已发布、有效且现场核验的数据交付；任何候选数据不能替代。
3. 有向路由、封路版本监控和失败关闭控制已编码，但无官方发布快照、真实封路 SLA 和双向现场复走时必须保持不可用。
4. WGS84 存储与坐标来源/转换字段已建模；尚未完成正式 GIS 数据、坐标控制点和显示层转换的生产级核验。
5. H5/PWA 只可按前台受控使用设计；后台/锁屏定位、系统权限、浏览器语音和离线能力受设备、浏览器和现场网络限制。
6. 高德只是候选展示/外跳服务，绝非内部路线引擎；未确认合同与权利前不得缓存其瓦片或把候选结果写入正式路线。
7. 远程 AI 默认关闭；代码中的 Schema 和来源校验不构成已审核知识、模型合规、宗教/文化审核或实时运营答案。
8. 生产数据库、OIDC/MFA、告警、备份/PITR、恢复、供应商合同、备案和法律审核没有仓库可验证的完成证据。
9. 私密分享、导出、删除和同意接口已有代码边界，但真环境 Referer/缓存/日志、跨设备撤销、保留期和 DSAR 履约均未取证。
10. 2026-08-15 干净隔离候选的生产构建成功，TypeScript 与 lint 零错误，Node 318/318 和全量 Playwright 34/34（约 5.5 分钟）通过；该自动化证据不是部署、真库、真机、现场或生产发布证据，候选变更后也必须重新运行。
11. `npm run verify:demo` 已通过，但 `npm run verify:release` 因未提供一次性 `DATABASE_TEST_URL`、`ALLOW_DATABASE_INTEGRATION_TESTS=1` 与 `DATABASE_TEST_CONFIRM_DISPOSABLE=1` 在 `test:db` 连接前停止；未连接或改动任何真实数据库。N10/N12 真库脚本和临时 PostGIS CI 已覆盖全部迁移/补偿、N6–N12 GIS/运营职责分离、N9 最终写入故障回滚与 N12 动态观测发布探针，但本提交尚无实际真库运行结果。严格 P0 账本记录 49 项非通过和 9 项外部阻断，结论仍为 `NO_GO`。
12. 公开 UGC、社区、付费、多景区、原生 App、AR 和游戏不在 P0 范围；任何 demo-only 后台或实验地图模式不得作为生产控制面。
13. 遇到未知、过期、撤回、网络不可用、低精度或无安全替代路线时，产品应停止或明确显示不可用，而不是继续推测性引导。
14. 新增的 `/navigation-lab` 是完全虚构、无真实对应的确定性算法演练：不调用高德、不读取设备定位、不写正式表，并在生产环境默认关闭；它证明软件闭环，不证明六祖镇内部导航可用。
15. PWA 已补齐 Android/iPhone 标准图标、主屏安装元数据和安装说明。Android 测试壳仅申请联网权限、固定单一 HTTPS 主机且不开放定位；当前仅为 debug/v2 测试签名，尚无模拟器或真机安装证据，不能替代签名 release 包、AAB 或商店审核。
16. 当前 Vercel Preview 基础地址受身份保护；受控分享入口等同测试访问凭证，撤销后绑定它的 APK 会失效。旧 Production 域名仍是上一版冻结演示，不是当前候选。
17. Windows 无法构建、签名或真机验证 iOS IPA；当前 iPhone 候选路径是 Safari PWA，且尚无 iPhone 真机证据。原生 IPA 必须转到 macOS/Xcode、Apple Developer 签名与真机矩阵。
18. 软件现可表达索道与观光车交通段，但当前没有任何六祖镇官方线路、上下客点、班次、票价、即时排队、停运或无障碍核验数据。两类交通默认不参与规划；即使静态服务资料完整，也必须由当前运营快照明确开放，未知或过期时停止使用。
19. 软件现可提交、独立复核并发布最长六小时的客流/天气耗时观测，但当前没有六祖镇正式采样源、传感器校准、人工计数规范、代表性评估、异常值规则、值班责任、更新 SLA 或现场真机证据。UGC 数量、主观印象和未校准单点不得作为动态路线权重；无正式观测时继续显示未知，不得推测。
20. 软件现可在确认偏航或正式版本变化后自动进行确定性重路由，但尚无六祖镇真机 GNSS、多路径遮挡、正式节点密度、连续偏航、弱网/断网、封路改道与反复重算抖动的现场证据。定位超过 10 秒、精度差于 35 米、无法保守贴合正式节点、完整快照不可用或没有不同指纹的新路线时，系统会继续停止导航；不得以旧路线、候选几何或外部提供方结果补位。
21. 软件现只在正式道路边界生成转向，并按逐边发布距离计算剩余量；这依赖管理方把真实路口、换乘点和需要口令的决策点正确拆成边，并提供经过量测的距离。浏览器定位精度圈只是设备报告的不确定性范围，不证明实际误差服从圆形分布。正式边分段、距离量测、真机多路径表现、地图颜色理解和现场口令均未验收。
22. 软件现用短时进度连续性包络抑制重叠/相邻道路的远端跳变，并用连续三个可靠样本识别反向行走；固定的 15 米匹配缓冲、20 米反向门限、三点滞回和 8 米恢复带尚未用六祖镇正式交叉路、平行路、回头路、陡坡、索道/观光车和代表性手机现场标定。算法警告不能证明游客实际朝向，也不能替代罗盘、现场标识或安全人员判断。
23. 地图的灰色已走线和蓝色剩余线来自设备内最后一次可靠路线投影，不是服务器保存的轨迹；定位低精度或暂停时会冻结在最后确认位置，进度无效时回退为整条蓝色待走线。长路线、复杂多段几何、索道/观光车换乘、低端手机 GPU、缩放/旋转、色觉/强光与现场游客理解尚未验收，颜色不能作为唯一安全信息。
24. 地图相机现区分自动跟随、手动浏览和剩余路线总览；手势或总览后不会被 GPS 更新强制拉回，只有显式回中才恢复跟随，低精度/停止状态不会驱动相机。该行为尚未覆盖代表性 Android/iPhone、Safari/Chrome/微信内置浏览器、多点触控、系统缩放、旋转、前后台切换、低端 GPU 和现场游客任务测试，浏览器自动化不能替代真机验收。
25. 页面生命周期现覆盖 `visibilitychange`、`pagehide/pageshow` 与浏览器支持时的 `freeze/resume`：后台会停止定位并清除重算最近定位，回前台先复核正式快照且不会自动恢复。不同手机和内置浏览器对锁屏、BFCache、内存回收、后台节流、权限撤回与进程终止的实现差异仍必须真机验证；系统完全回收页面时只能重新加载和重新规划，不能承诺无缝续航。
26. 正式导航现可由游客显式开启浏览器前台关键语音，并在后台、暂停、定位不可靠、偏航或版本失效时取消旧播报；它不录音、不上传音频，也不替代屏幕和现场标识。Web Speech 的可用声音、中文发音、自动播放策略、系统静音、音频焦点、耳机/蓝牙、来电抢占和后台行为因 Android/iPhone、Safari/Chrome/微信内置浏览器而异；核心安全任务不能依赖语音单通道，仍需真机和现场验证。
