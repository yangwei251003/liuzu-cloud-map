      RUN FROM SOURCE

      本地打开完整网页

      准备 Node.js 24，下载仓库后在项目目录执行：

      npm ci
npm run build
npm run start

      打开 http://localhost:3000。默认不提供真实账号、地图 Key 或模型服务。生产身份、正式路网与运营能力需要单独配置 PostgreSQL/PostGIS、提供方和审核证据。

      同一家族，分别保存

      main：访客导览、地图治理、个人旅程与新增动效。
      three-role-mvp：游客、商户、运营流程的独立演示开发线。
      Vite 版本：另一套文化展示站与本地集章后台。

      不同开发线不会相互覆盖，具体运行与未验证范围以各自 README 为准。
