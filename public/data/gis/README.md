# 候选地理资料与许可

这里的 buildings / roads / waterways / pois GeoJSON 来自 OpenStreetMap 公开地理要素的项目截取与格式整理，按 Open Data Commons ODbL 1.0 提供，版权为 © OpenStreetMap contributors。见 https://www.openstreetmap.org/copyright 与 https://opendatacommons.org/licenses/odbl/1-0/ 。继续分发/改编数据库需遵守 ODbL，不能改成本项目 MIT。

各要素保留 osm_id、source、source_url 与坐标系字段。公开副本去除 tags_json 中的联系方式、地址、owner/operator/payment 字段；不包含个人轨迹或用户位置记录。地图数据不证明景区边界、道路安全、当前出入口、坡度、无障碍或开放状态。公众文化背景资料与官方来源见 docs/DATA_SOURCE_REGISTER.md；官方高层介绍不能验证本数据的每个坐标。

prototype-routes 是本项目早期候选连线演示，禁止用作正式导航。route-network-manifest.v1.json 是无入口、节点或边的 DRAFT 空快照，正式路由失败关闭。没有采集/公开真实游客轨迹，OSM 候选要素不写成官方景区内部导航路网。
