# 六祖云游功能地图

状态：`GATE_2_APPROVED_BASELINE`  
版本：`Blueprint V0.1`  
基准日：2026-08-14（Asia/Shanghai）  
阶段边界：第二阶段功能蓝图；不代表已开发、可用或已通过 Gate 2。

## 0. 功能分层口径

| 标记 | 含义 |
|---|---|
| `MVP-S1` | 完整 MVP 的现场可信切片；可先作为 PoC 验证 |
| `MVP-S2` | 完整 MVP 的差异化切片；不得从 MVP 静默删除 |
| `MVP-支撑` | 两个游客切片可信运行所必需的运营、审核、安全与资产能力 |
| `PoC` | 只用于验证高风险假设，不等于产品交付 |
| `后续` | 有平台化预留价值，但不进入首版 |
| `禁止承诺` | 数据、权利或端侧能力未证明时不得对外宣称 |

完整价值 MVP = `MVP-S1 + MVP-S2 + MVP-支撑`。只交付 `MVP-S1` 必须命名为“现场可信 PoC”，不能宣称已经完成原始产品价值闭环。

## 1. 一级功能树

1. 游客入口与范围认知
   - 景区/核心区层级说明
   - 自驾、高铁/接驳到达方式
   - 当前状态、未知项与官方渠道
   - 已保存行程入口
2. 游记/需求结构化
   - 合法输入与用途确认
   - 原文证据提取
   - POI 候选与消歧
   - 时间、交通和行动约束确认
3. 行程与路线
   - 可执行性校验
   - 行程编辑、排序和重验
   - 公共道路与内部路网衔接
   - 封闭、不可达、范围外与过期处理
4. 现场导览
   - 前台定位与精度状态
   - 标准地图/主题皮肤切换
   - 路线进度和等价路线列表
   - 手动“我已到达”、暂停/恢复/结束
   - 弱网、权限、后台与地图故障降级
5. 文化讲解与 AI 助手
   - 已发布文字/音频讲解
   - 事实类型、来源、核验时间和争议
   - 受控单编排问答、只读白名单工具
   - 无证据拒答与高风险转人工
6. 足迹、保存与分享
   - 轻量打卡与知识卡收藏
   - 私有计划/足迹
   - 字段预览、可撤销/到期链接
   - 删除、撤回与状态重新校验
7. 运营状态管理
   - 开放、封闭、限制、停车、接驳、活动等状态
   - 来源、责任人、有效期、审核和紧急发布
   - 过期降级、撤回和审计
8. 文化内容与讲解资产治理
   - 命题、来源、事实类型、许可、版本
   - 文化/宗教/文保审核
   - 文稿、字幕、真人/合成音频和生成标识
   - 发布、过期、撤回与下架联动
9. GIS 与路线资产治理
   - 多层边界、入口、节点、设施、道路/步道
   - 坐标系、来源、现场轨迹、可达性和版本
   - 公共/内部网络隔离与核验入口连接
   - 临时封闭、发布和回滚
10. 平台保障
    - 身份、角色和职责分离
    - 隐私同意、最小化、删除与链接控制
    - AI/路线/内容黄金集与发布门禁
    - 纠错、审计、质量、成本和故障可观测性

## 5. 权威来源与功能边界

| 信息类型 | 产品唯一允许的事实来源 | AI 的角色 | 来源不可用时 |
|---|---|---|---|
| 坐标、入口、内部路径、设施 | 经多源、管理方和现场审核后发布的 GIS 对象 | 解释候选和用户意图；不创造几何 | 阻塞导航/路线；回退现场标识/人工 |
| 公共道路路线 | 获准地图服务在请求时返回的结果 | 构造经校验参数、解释限制 | 不画直线；提供入口文字与人工回退 |
| 开放、封闭、停车、接驳、客流、活动 | 有责任主体与有效期的官方源/运营发布 | 概括结果，不改写状态 | 显示无法核验，不沿用过期信息 |
| 历史、宗教、传说、解释 | 已发布命题级知识与相应审核 | 检索、引用、不同长度解释 | 拒答或并列冲突，不用 UGC/营销补全 |
| 用户偏好与计划 | 用户本次明确输入和确认 | 提取候选、提出可撤销建议 | 让用户手工编辑，不推断敏感偏好 |
| 游客体验/纠错 | 私有 UGC 或待核验反馈区 | 总结线索，不升级为官方事实 | 保持待核验，不改变游客端事实 |

## 6. 跨功能状态联动

| 上游变化 | 受影响功能 | 强制行为 |
|---|---|---|
| POI/入口撤回 | 行程、地图、到达、分享 | 相关行程从 `READY` 失效；不再提供可导航入口；分享提示重新校验 |
| 路段封闭/过期 | 路线、现场会话、分享 | 阻塞或暂停相关段；只有经核验替代才恢复 |
| 运营状态过期 | 行前、路线、现场提醒 | 降为未知；不得继续显示“已确认开放” |
| 文化命题撤回 | AI 回答、讲解、知识卡、分享 | 停止检索/播放，显示已撤回或更新说明 |
| 音频许可到期 | 到点讲解、离线内容 | 音频不可用，保留已审核文字（若文字权利仍有效） |
| 用户撤销分享 | 分享访问与缓存 | 链接立即失效，搜索/预览缓存按设计清理 |
| 用户删除游记/行程 | 原文、结构化候选、路线、分享、评测副本 | 按告知范围联动删除；必要审计只保留最小合规字段 |
| 模型/提示/工具变更 | 提取、问答、路线参数解释 | 先跑对应黄金集，零容忍缺陷为 0 才可发布 |

## 7. 数据采集与指标功能边界

MVP 需要验证产品价值，但不能以过度采集换取指标：

- 可采：任务开始/完成、步骤失败类型、选择的到达方式、是否使用手动降级、状态更新耗时、匿名化反馈类型；
- 最小化后可采：粗粒度路线进度、讲解完成/跳过、用户主动纠错；
- 默认不采：连续原始轨迹、常开麦克风、声纹、人脸、宗教信仰或仪式行为画像、未成年人身份、原始游记全文的长期分析副本；
- 必须先告知/单独确认：精确位置、语音、敏感行动约束、跨设备同步、链接分享、将内容进入评测或研究样本；
- 商业指标、推荐画像或跨景区追踪属于后续新目的，必须重新评估和授权。

## 8. 明确延后与禁止膨胀

| 延后能力 | 延后原因 | 重新进入评估的前提 |
|---|---|---|
| 全 3D 数字孪生/东方数字禅境 | 不先解决入口、路线、状态和内容可信；资产/性能/版权成本高 | 现场核心闭环指标成立，另获大型功能确认 |
| AR 寻宝、完整剧情/游戏 | 宗教文保场景风险、内容与安全负担 | 明确非敏感区域、文化审核、现场运营与用户价值证据 |
| 全镇全域导航 | 边界、道路、管理主体和动态状态未闭合 | 分区 GIS 和责任数据源逐步发布，另获范围扩张确认 |
| 多景区 SaaS 后台 | 首版只验证六祖镇实例 | 单景区闭环与运营资产模型成立，另立平台化项目 |
| 公开 UGC/排行榜/售卖 | 版权、审核、隐私、未成年人和商业运营显著扩张 | 合同、审核、申诉/下架、治理与商业方案经人工确认 |
| 支付、商城、直播、广告 | 不属于首期四项商业验证目标 | 独立业务、成本、合规与用户价值论证 |
| 长时后台定位/语音监听 | 端侧、审核、隐私、耗电和体验风险 | 真实需求、载体 PoC、单独同意与法务评估 |
| 多 Agent | 延迟、成本、可追踪和越权风险 | 单编排评测不能满足明确任务，收益经同集实验验证 |

## 9. 功能变更门槛

新增或提前任何功能前，必须回答：

1. 是否增强“真实可执行的深度导览”核心体验？
2. 是否直接服务首发游客或支撑其可信运营？
3. 是否保留未来多景区复用边界而不提前建设 SaaS？
4. 是否增加数据、版权、宗教、隐私、安全、供应商或长期成本？
5. 若不做，完整价值 MVP 是否仍然不能成立？

中等新功能需提交价值、开发/维护成本和路线影响；大型扩张、核心架构、长期付费或新供应商必须由用户确认。任何变更不得绕过 Gate 2 与开工前验收。
